# WP03 Section F R500 — Cinnamon Toast Crunch family picker reassessment (2026-10-17)

## Disposition

- **Decision:** Retain a bounded hold on the proposed plain `Cinnamon Toast Crunch cereal / céréales Croque Cannelle` identity. Current Canadian and Québec-facing retail evidence now confirms several separate Toast Crunch products, but the reviewed sources do not establish a current, stable Canadian family roster or a reliable bilingual family-query scope.
- **R358 status:** This reassessment supersedes [R358's proposal](wp03-section-f-next-gap-review-r358-20261016.md) and [integration README](../batches/wp03-section-f-cinnamon-toast-crunch-family-picker-hold-integration-r358-20261016/README.md) statement that sibling availability was unverified: several siblings are now listed by Canadian retailers, including current Québec-facing retailer records. It does not resolve the family picker question, so the plain product remains outside active references and the shared research ledger.
- **Data effect:** No ingredient reference, ID, alias, form, legacy mapping, ledger record, recipe link, measure, conversion, yield, or substitution is proposed. No shared catalog, ledger, plan, roadmap, workflow, or generated file changed.
- **Prior candidate wording:** R358's `Cinnamon Toast Crunch cereal / céréales Croque Cannelle` remains a candidate phrase only. This review does not allocate an ID or approve active fields.

The evidence is stronger than the original R358 snapshot. A current Provigo Québec-facing catalog lists the plain cereal alongside French Toast Crunch, CinnaGraham Toast Crunch, Waffle Maple, and Strawberry Toast Crunch products. The strawberry item has matching English/French Provigo records and was shown in stock at a Longueuil store. Other Canadian retailer records add Churros, a filled/Loaded product, and a limited Saja Boys edition, with different stock and regional signals. General Mills Canada's current brand pages do not enumerate its current Canadian SKUs; its most recent Canadian cereal product list found here is dated September 2023 and differs from today's retailer listings. A single plain-cereal row would therefore still present one result for brand queries while multiple current or recently listed products remain unrepresented.

The hold is limited to deciding the active catalog representation of this branded family. It does not claim that any observed sibling is fictional, discontinued, or unavailable throughout Canada.

## Phrase-first picker projection

The static projection follows [`IngredientSearch.kt`](../../../app/src/main/java/app/recipebook/domain/localization/IngredientSearch.kt): lowercase and compatibility-fold the query, remove accents and punctuation, return complete normalized word-phrase matches first, then use substring matching only when no complete phrase matches. Reference and attached-form terms are included. This is a static projection, not Android picker QA.

| Query | Current catalog | If R358's plain product alone were added | Consequence |
|---|---:|---:|---|
| `Cinnamon Toast Crunch` | 0 | 1 | The base would look like a complete family choice despite current retailer evidence for distinct siblings. |
| `Croque Cannelle` | 0 | 1 | The Québec-facing brand wording would likewise select only the base. |
| `Céréales Croque Cannelle` | 0 | 1 | The held French candidate phrase is a singleton. |

| `French Toast Crunch` / `Croque Pain Doré` | 0 / 0 | 0 / 0 | The separately named product does not match the plain brand phrase. |
| `Strawberry Toast Crunch` / `Croque Fraise` | 0 / 0 | 0 / 0 | The paired current Provigo sibling remains unrepresented. |
| `Saja Boys Secret Flavor` / `Croque Cannelle Churros` | 0 / 0 | 0 / 0 | Current or recently listed sibling records remain unrepresented. |
| `cereal` / `céréales` | 56 / 52 | 57 / 53 | A single generic-class term in each display would add one result to each broad query. |
| `rice cereal` | 2 | 2 | The existing baby-rice and crispy-rice cereal results remain unaffected by the candidate. |

The family query is not naturally shared by every product title: `French Toast Crunch` and `Croque Pain Doré` do not contain the base brand phrase, while `Strawberry Toast Crunch` / `Croque Fraise` uses another product name. Promoting several rows would require a reviewed rule for which siblings receive shared family search terms and how the bilingual query sets correspond. The R488 Chex precedent could add a bounded set because each proposed bilingual display already carries `Chex`; here the shared Cinnamon Toast Crunch / Croque Cannelle terms on differently named products would have to be inferred from retailer grouping. No current manufacturer roster or explicit family-level search policy supports that assignment. The hold keeps the picker from implying a singleton family or guessed family aliases.

## Reconsideration condition

Reopen the hold when a current Canadian manufacturer source enumerates the offered Cinnamon Toast Crunch / Croque Cannelle cereal SKUs with current status and bilingual product names, or when the integration owner explicitly scopes a Québec-facing retailer set and verifies a stable current product page for each included SKU. The review must decide how to handle limited editions and how the `Cinnamon Toast Crunch` and `Croque Cannelle` family queries should surface siblings whose individual names do not contain those phrases.

If the family is later accepted, keep each distinct flavor/product as its own `GRAIN_AND_CEREAL` identity. Do not infer forms, formula links, density, unit mappings, reusable measures, package conversions, yields, recipe links, or substitutions from cereal descriptions or package sizes. The 1-cup/gram servings and net package weights found on retailer pages remain product-specific evidence only.
