# WP03 Section I — kola-nut regional kernel identity review (R373)

- **Review date:** 2026-10-16
- **Status:** proposal only; no shared catalog, ledger, recipe, plan, roadmap, batch, code, or test files changed
- **Scope:** one new regional culinary seed candidate, the true kola nuts sold as seeds of *Cola acuminata* and *Cola nitida*
- **Method:** inspected the live split seed package, forms, legacy-import identities, research ledger, Section I checklist, proposal archive, and every manifest-listed recipe; checked bilingual product wording, taxonomy, and picker effects against current Québec/Canadian and authoritative sources

## Recommendation

Integrate one identity-only reference, **ingredient-ref-kola-nuts**, in **NUT_SEED_AND_DRIED_FRUIT**:

| Field | Proposed value |
| --- | --- |
| English display | **kola nuts** |
| French display | **noix de kola** |
| English alias | **kola nut** |
| French aliases | none |
| Product scope | Edible seeds sold as kola nuts from the two source-supported true kola species, *Cola acuminata* and *Cola nitida* |
| Density and unit mappings | null / empty |
| Forms, measures, links, yields, conversions, substitutions | none |

This fills the open [Section I checklist item](../../RecipeBook-global-ingredient-catalog-plan.txt) for additional melon-seed products and regional culinary kernels. The already-reviewed [magaz/magaj boundary](wp03-section-i-magaz-melon-kernel-product-boundary-review-20261011.md) and [current Québec/Canadian melon-kernel listings](wp03-section-i-melon-seed-regional-kernel-gap-review-20261011.md) remain closed as recorded; this review does not reopen their holds. OQLF lists **noix de kola** and English **kola nut**; Kew identifies *C. nitida* and *C. acuminata* as the principal “true kolas,” and a Canadian product seller explicitly identifies a sold kola-nut item as *C. acuminata*. Québec and Canadian listings show local trade and beverage use. The evidence supports a narrowly named seed identity, but not a form, a default use state, or recipe behavior.

Keep the following wording out of aliases: **cola**, **cola nut**, **cola nuts**, **cola seeds**, **noix de cola**, **bitter kola**, **bitter cola**, **petit cola**, **gbanja kola**, **bissy nut(s)**, **guru nut(s)**, **Abata cola**, and **monkey kola**. Some are source-specific market terms; several have cross-species or beverage collisions. OQLF’s **noix de cola** remains recorded as a source-attested variant, but it is not needed for the Québec display.

Do not merge this identity with kola extract or cola syrup. Do not merge **bitter kola** / **petit cola**: the reviewed Québec listing groups those names with kola nuts, while Kew’s medicinal-name index associates “bitter cola” with both *Cola nitida* and *Garcinia kola*. Keep *Garcinia kola* outside this candidate unless a future product-specific review establishes its own scope. Although one retailer describes raw, roasted, and ground use, treat those as seller-specific preparation claims; do not create forms or generalize handling or safety instructions.

## Picker and recipe-demand audit

The picker projection followed **IngredientSearch.kt**: complete normalized word-phrase matches take priority, with substring fallback only when there is no phrase match. This was a static code-based projection, not an Android picker observation.

| Query | Current result | Result with the proposed name and singular English alias |
| --- | --- | --- |
| **kola nut**, **kola nuts**, **noix de kola**, **kola** | No match | Only the proposed kola-nut reference |
| **bitter kola** | No match | No match |
| **cola** | 13 fallback matches, including chocolate-named references | Same existing fallback matches; no kola-nut result |
| **cola** with **noix de cola** added as an alias | The current fallback matches | The alias would become a complete-phrase match and return only the kola-nut row |
| **nuts** / **noix** | Broad generic and species/product results | One expected additional seed/nut result |

This picker behavior is why the proposal uses the OQLF-listed **noix de kola** display, keeps the English spelling **kola** in the display/alias, and leaves **noix de cola** as research evidence rather than an active alias. It avoids letting the alternate French spelling capture the broad English **cola** query and replace its existing fallback results.
