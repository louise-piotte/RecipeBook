### Audit results

- Three active references contain a malt term: `ingredient-ref-malted-barley-flour` (`malted barley flour` / `farine d'orge maltée`, EN alias `malt barley flour`), `ingredient-ref-malted-wheat-flour` (`malted wheat flour` / `farine de blé maltée`), and `ingredient-ref-roasted-wheat-malt-flour` (`roasted wheat malt flour` / `farine de malt de blé torréfié`). The first two are the existing flour identities; the third is a separately declared roasted product with an unresolved detailed process. All three are `FLOUR_AND_STARCH` and have no forms, densities, unit mappings, or substitution rules.
- Complete searches for `malted barley flour`, `malt barley flour`, and `farine d'orge maltée` return only the existing malted-barley-flour reference. `malted wheat flour` and `farine de blé maltée` return only the existing malted-wheat-flour reference. The two exact roasted-wheat-malt names return only their existing separate row.
- A broad `malt` query currently returns the barley-flour reference (through its `malt barley flour` alias) and roasted wheat malt flour. It is therefore not a safe alias for any new extract or malt identity. `malt flour` matches the separately named roasted wheat malt flour. No generic `malt flour` alias should be added to either existing malted-flour identity.
- No active reference, form, or legacy candidate contains a complete search phrase for malt extract, malt syrup, enzyme activity qualifiers, malt powder, or a dough improver. No legacy candidate matched the tested names or aliases.
- All 114 bundled recipes and 1,123 ingredient rows were audited; **zero** rows matched the in-scope names or aliases. The full JSON text search also found no match. No recipe line needs relinking.

## Evidence and naming decisions

| Product/concept | Evidence-backed boundary | English / fr-CA naming recommendation | Alias and identity disposition |
| --- | --- | --- | --- |
| Malted barley flour | Already a distinct milled product. The existing row is supported by OQLF, CFIA, and a Canadian mill; its source describes germinating, drying, and grinding barley. | Retain `malted barley flour` / `farine d'orge maltée`. | Keep existing `malt barley flour` EN alias. Do not add `malt flour`, `malt powder`, `malt extract`, or `malt syrup` to this identity. Do not create another identity for diastatic/non-diastatic barley flour. |
| Malted wheat flour | Already separate from malted barley flour, ordinary/whole-wheat flour, and vital wheat gluten. | Retain `malted wheat flour` / `farine de blé maltée`. | Keep aliases empty. Do not reuse the barley-flour alias or add broad malt terms. |
| Roasted wheat malt flour | Existing separately declared ingredient; its existing research says the declaration does not establish a detailed manufacturing process. | Retain `roasted wheat malt flour` / `farine de malt de blé torréfié`. | Keep it separate from ordinary malted wheat flour and roasted wheat flour; no generic malt alias. |
| Diastatic / non-diastatic malted flour | Manufacturer evidence distinguishes enzyme-active malt flour from malt processed to inactivate enzymes. This is a meaningful product qualifier, not a synonym. Wheat and rye as well as barley may be malted; the cereal remains material. | Use explicit source-supported qualifiers only when a recipe or exact product gives them. Possible provisional labels: `diastatic malted barley flour` / `farine d'orge maltée à activité diastasique`; `non-diastatic malted barley flour` / `farine d'orge maltée sans activité diastasique`. Apply the same pattern to wheat only when cereal is explicit. Independent Québec French review is pending. | Do not make these qualifiers global aliases or separate ingredient IDs. If an exact recipe later requires state capture, consider source-qualified forms attached to the existing cereal-specific flour reference. Do not infer enzyme activity from an unqualified `malted flour` label. |
| Malt extract | OQLF gives the preferred Québec French term `extrait de malt`, English `malt extract`, and says it occurs as liquid or powder. Briess describes malt extract as a concentrated extract and notes that malted grains other than barley can be extracted when named accordingly. This is an extracted soluble product, distinct from flour milled from whole malt. | Candidate identity if a recipe requires it: `malt extract` / `extrait de malt`; provisional stable ID `ingredient-ref-malt-extract`, category `BAKING_MIXIN_AND_PANTRY`. Record the source cereal when stated; keep `malted wheat extract` qualified rather than folding it into a barley-specific product. | No candidate aliases yet. Do not alias `malt powder`: it can be confused with ground malt flour and dried malt extract. Do not alias roasted malt flour or any dough improver. |
| Liquid/dry malt extract and activity | OQLF directly supports liquid and powder presentations. Briess sells liquid and dry extract products and documents that diastatic extract is possible when extraction conditions preserve some alpha-amylase; commercial extracts can also be nondiastatic. Physical state and enzyme activity are separate qualifiers. | If a recipe later needs forms, use explicit labels such as `liquid malt extract` / `extrait de malt liquide` and `dried malt extract` / `extrait de malt en poudre`. Add diastatic activity to the full form/product label only when the source states it. | Do not activate forms now: there are no recipe matches, and no source supports a complete universal set of cereal × physical-state × enzyme-activity combinations. Do not add liquid-to-powder conversions. |
| Malt syrup | FDA’s U.S. guidance says “malt syrup” and “malt extract” have sometimes been used interchangeably for concentrated water infusions, but it restricts the unqualified terms to barley and requires naming other malted grains. The Canadian bread standard lists `malt syrup`, `malt extract`, and `malt flour` as separate permitted ingredient names without defining their equivalence. | Keep `malt syrup` / provisional literal `sirop de malt` unresolved as a global identity or alias. For a specific verified pure barley extract product, it may be a liquid-form label or source-specific search term after Canadian product-label review. | Do not create a parallel generic identity or global alias from the U.S. guidance alone. Do not map `malted cereal syrup`, blends, or other-grain syrups to unqualified `malt extract` without exact composition and label evidence. |
| Dough/bread improver | This is a variable functional product family. Québec supplier Puratos describes full multi-use and modular solutions; one product listing is not a formula for the class. A Québec food-directory listing for one bread mix names `dough improver (enzyme, ascorbic acid)` separately from malted barley flour. Briess lists named Maltorose products with specific malt-flour/dextrose or malt-flour/wheat-flour/dextrose compositions and specific Lintner activity. | OQLF’s 1987 bread-improver entry lists `améliorant de la fermentation` and `améliorant de la panification`, but its note describes oxidizing agents used to mature flour. Current Québec supplier wording `améliorant à pain` is a clearer broad family label, not an official composition standard. Use product-specific bilingual labels where a recipe names a product. | Do not add generic `dough improver` / `bread improver` as an alias for malt, extract, or any single compound. Keep a composition-known improver as a product-specific compound candidate only if an exact recipe/product declaration warrants it. No bundled recipe currently does. |

## Measurements and substitution claims

No general malt or improver density, cup/spoon weight, package yield, recipe measure, or weight/volume conversion is supported by these sources. Liquid and powder are materially different states, and extract solids/water content vary by product. Keep all `defaultDensity`, `unitMappings`, and form densities empty unless a future named product has a source-specific measurement that applies to a stated method and product.

Briess gives example bakery-use ranges and product-specific diastatic-power values in degrees Lintner. These values characterize its products and industrial formulation guidance; they are not a general kitchen dose, conversion, or product-equivalence rule. Maltorose’s 20° Lintner and Maltorose 60’s 60° Lintner belong to those named formulations only. Do not store those values as defaults for diastatic malt.

Do not infer substitutions among diastatic and non-diastatic products, flour and extract, malt extract and malt syrup, or malt and a dough improver. The sources show different solids, cereal sources, enzyme activity, and compound ingredients. Any future substitution would need an exact source product, composition/activity, recipe role, and scoped method; none is established here.

## Coordinator integration recommendation

1. Keep `ingredient-ref-malted-barley-flour`, `ingredient-ref-malted-wheat-flour`, and `ingredient-ref-roasted-wheat-malt-flour` as the only existing malt-containing flour identities in this scope. Preserve their current names, aliases, categories, and no-numeric/no-form state. Do not make any duplicate flour row.
2. If the coordinator wants a generic extract identity for future recipes, add only `ingredient-ref-malt-extract` with `malt extract` / `extrait de malt`, category `BAKING_MIXIN_AND_PANTRY`, empty aliases, null density, and no mappings or substitutions. Record cereal source on an exact product/recipe when known. The ID and record are not allocated by this proposal.
3. Keep `malt syrup` / `sirop de malt` conditional rather than a global alias. Resolve it against an exact Canadian product label; attach it only to a verified barley liquid-extract product or form if the source justifies that mapping. Leave `malted cereal syrup` and mixed syrups separate or unresolved.
4. Treat diastatic/non-diastatic as explicit product-state qualifiers, not aliases. If a later recipe requires them, attach bilingual, cereal-specific forms to the already existing flour reference or to an exact extract product; use product-specific activity data only. Obtain independent Québec French review for the qualifier wording.
5. Keep generic dough improver unresolved. Add no `bread improver` alias to malt or extract. Consider a composition-known improver only as a separately named compound/product when an exact recipe line identifies that product and its source composition.
6. Leave density, unit mappings, package yield, liquid/dry conversion, activity-dose defaults, flour/extract conversions, and all substitutions inactive. Close only this Section E item after the coordinator accepts the boundaries and confirms whether any future source-specific identity is needed; the wider Section E list remains open.
