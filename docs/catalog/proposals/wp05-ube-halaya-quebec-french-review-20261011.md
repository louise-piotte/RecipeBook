# Coordinator's independent Québec French review: ube halaya

- **Reviewed:** 2026-10-11
- **Status:** Independent fr-CA wording review; proposal only. No catalog, ledger, recipe, or code changes.
- **Target:** Existing `ingredient-ref-ube-halaya`, displayed as `ube halaya (purple yam jam)` / `confiture d’ube (ube halaya)`.
- **Scope:** Review the descriptive French display and alias. This does not reopen the identity, its category, or the product-specific English alias `purple yam jam`.

## Recommendation

Retain `confiture d’ube (ube halaya)` as the Québec French display and `confiture d’ube` as its descriptive French alias. Keep the native product name `ube halaya` in the display. This wording has local menu evidence in Québec and appears in a Canadian bilingual cooking handout. Treat it as a descriptive name, not an OQLF-standardized term or a bilingual retail-label transcription.

Do not add `ubé`, `igname violette`, or `confiture d’igname violette` as aliases. The acute accent occurs in one Québec menu's adapted spelling, while the Filipino product name and other Canadian sources retain unaccented `ube`. A generic purple-yam description also risks being read as purple sweet potato. OQLF's general *igname* entry does not identify *ube* or supply a prepared-product name [S01–S03].

The local menu uses `confiture d'ubé (igname pourpre)` for an ube-jam cheesecake filling [S01]. A Canadian bilingual handout calls the same prepared filling `confiture sucrée d'Ube` in French and “a sweet Ube jam” in English [S02]. The handout elsewhere confuses ube with sweet potato and has other translation inconsistencies; only its use of the spread wording is considered here. These sources support the existing descriptive wording while leaving the Filipino name visible.

## Decision and limits

- Retain the current bilingual display and the `confiture d’ube` French alias as descriptive Québec wording; do not claim formal standardization.
- Keep `ube` unaccented and retain `ube halaya` in the French display so users can recognize the Filipino product name.
- Do not add generic yam, purple-sweet-potato, flavoring, or other jam terms as aliases.
- The separate `ube jam` alias remains inactive pending a market-specific identity review; this French wording review does not settle English product-name variation.
- No tests were run; this was a naming review with no database JSON changes.
