# WP05 Preserved Condiments: Exact Recipe Demand Review (2026-10-10)

- **Status:** Proposal only; no bundled package, research ledger, recipe, plan, roadmap, or test file was changed.
- **Scope:** Sauerkraut, pickled cucumbers, olives, pickled onions, chutneys, and relishes. The scan covers every ingredient row in the current bundled recipe manifest.
- **Recommendation:** Retain and source-review the existing bread-and-butter-pickle identity and its exact recipe link. Hold new identities or links for the other requested products because no exact bundled recipe line demands them. Treat olive-oil lines as oil, not olive-fruit demand.
- **Limits:** No recipe text that says only cucumber, onion, or olive oil is promoted into a preserved product. The prior capers/caperberries boundary review is context only and is not repeated here; see [the completed WP05 cooking-sauces review](wp05-cooking-sauces-exact-recipe-demand-review-20261010.md). Piccalilli and giardiniera are outside this six-product audit.

- Live reference records relevant to the boundaries are `ingredient-ref-bread-and-butter-pickle`, `ingredient-ref-cucumber`, `ingredient-ref-olive-oil`, `ingredient-ref-tapenade`, `ingredient-ref-sweet-mango-chutney`, `ingredient-ref-mango-pickle`, `ingredient-ref-lime-pickle`, `ingredient-ref-haitian-pikliz`, and `ingredient-ref-kimchi`. The table-olive, sauerkraut, pickled-onion, generic-chutney, generic-pickled-cucumber, and relish references are absent.
- The bread-and-butter pickle record currently displays EN `bread and butter pickle` / fr-CA `cornichons sucrés`, has the alias `cornichons bread and butter`, and has no density or unit mappings. Its exact recipe row already links to that ID. Brine&Co directly supports the English/French display pair (S04); this proposal adds no alias and does not assert the existing mixed-language alias as source-verified.
- `ingredient-ref-cucumber` is `cucumber / concombre` in `VEGETABLE_AND_AROMATIC`; it is not a preserved cucumber. `ingredient-ref-olive-oil` is in `FAT_AND_OIL`; it is not an olive-fruit identity. Existing tapenade, kimchi, pikliz, mango/lime pickle, and sweet mango chutney identities stay distinct.
- Proposal source IDs are `WP05-PRESCOND-20261010-S01` through `WP05-PRESCOND-20261010-S11`. A pre-write search found no collision for this prefix in the current docs, seed, or research ledger. The dated proposal path did not exist before this file was created; S11 was added during root source verification of the existing recipe link.
- The completed capers/caperberries review remains linked above and is not resubmitted. This audit makes no claim about piccalilli or giardiniera.
