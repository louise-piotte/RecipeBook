# WP02 pupuru — independent Québec French display review

- **Reviewed:** 2026-10-11
- **Disposition:** Retain borrowed `pupuru` as the provisional French display. Keep French aliases empty.
- **Scope:** Québec-facing wording for the active smoked, fermented cassava product; no identity, alias, form, or recipe integration is proposed.

## Recommendation

Keep the current `pupuru / pupuru` display pair, while leaving the French display marked provisional. The reviewed sources do not establish a Québec French label for the product. The French-language thesis in the existing identity review retains *Pupuru* as a borrowed name when describing its flour and prepared dough. The Canadian retailer listing reviewed for the identity is English-only and its contact page locates the store in London, Ontario. OQLF's `farine de manioc` entry names broad cassava flour made by dry-grinding roots; it does not identify smoked, fermented Pupuru.

Do not add `farine de pupuru`, `farine de manioc`, `farine de manioc fermentée`, or `farine de manioc fumée` as French aliases. A process description or broad cassava-flour term would not be a Québec-validated name for this product. Keep the existing English alias `pupuru flour` unchanged. This is a conservative borrowing decision, not a claim that OQLF or Québec retailers have standardized the name.
