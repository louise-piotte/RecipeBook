# WP04 Section P — scrod terminology boundary review (R712)

**Review date:** 2026-10-18  
**Recommendation:** Add only qualified, English search aliases `scrod cod` under the existing Atlantic cod reference and `scrod haddock` under the existing Haddock reference. Keep the bare term `scrod` unowned and do not add the seller spelling `schrod` on the current evidence. These are aliases for picker search only; leave the canonical display names unchanged.

## Scope and finding

The Section P finfish checklist remains open. This review selects one terminology boundary: whether the unqualified English word `scrod` should point to Atlantic cod, Haddock, or a third market group. Current evidence attaches scrod wording to both *Gadus morhua* and *Melanogrammus aeglefinus*. A single-species alias would therefore make an ambiguous word appear resolved.

Use the paired source-qualified phrases `scrod cod` and `scrod haddock` as English aliases on the already-existing species references. Under the current picker, the bare query `scrod` will then show both visibly qualified results, while either qualified phrase selects its matching species. Do not add bare `scrod` as an alias to either species, create a species-neutral scrod reference, infer a French alias, or associate `schrod` with a species based on one seller page.

No new reference or form is proposed. Do not change recipe links, measures, density, unit mappings, conversions, yields, or substitutions.

## Decision boundary

Add only search aliases `scrod cod` → existing Atlantic cod and `scrod haddock` → existing Haddock. Hold the bare `scrod` alias on either individual species, any species-neutral scrod identity, and `schrod`. Add no French alias because this review found no Québec authority for one.
