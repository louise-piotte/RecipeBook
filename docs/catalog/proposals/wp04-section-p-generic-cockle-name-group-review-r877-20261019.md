# WP04 Section P — generic cockle/coque name-group review (R877)

- **Review date:** 2026-10-19.
- **Open checklist parent:** “Mussel, clam, oyster, cockle, and remaining shellfish identities; scallop is integrated below” in the [global ingredient-catalog plan](../../RecipeBook-global-ingredient-catalog-plan.txt#L8356).
- **Candidate:** the existing unresolved ledger record `ingredient-ref-cockle`.
- **Recommendation:** promote that candidate in place to an identity-only, visibly qualified, species-neutral market-name group: **cockle (name used for multiple cockle species) / coque (nom utilisé pour plusieurs espèces de coques)**. This is a catalog name group, not a taxon, a complete species roster, or a claim that its member species are interchangeable.
- **Exact proposed catalog effect:** one qualified reference and its ordinary singular/plural search terms, if accepted. Do not add species rows, forms, package records, measurements, recipe links, conversions, yields, or substitutions in this review.

## Scope and prior-work boundary

The 2026-10-11 review held bare `cockle / coque` because the Québec OQLF entry tied `coque` to *Clinocardium ciliatum*, while CFIA also used `Coque` for other species, and no recipe selected a species. The existing candidate retained that evidence. R811 subsequently held Iceland cockle / `coque d’Islande` outside active data because its hypothetical bilingual row would have been the only result for the otherwise empty broad `cockle` and `coque` picker searches. R144 separately held Greenland cockle / *Serripes groenlandicus* for the same broad-query concern. Neither species-specific proposal allocated a reference or changed `ingredient-ref-cockle`.

This review asks whether the broad name itself can be represented with an explicit multi-species qualifier. Current evidence supports doing so. The exact collisions that made an unqualified single-species assignment unsafe are evidence for a visibly qualified name group when the group is not presented as one species. This follows the catalog pattern accepted for the generic oyster name group in [R871](wp04-generic-oyster-species-diversity-review-r871-20261019.md), while recognizing that the current cockle picker has no active species results yet.

Keep the generic clam / `palourde` candidate separate. Keep the R144 Greenland-cockle and R811 Iceland-cockle holds, all species/product evidence, and their no-demand findings unchanged. This proposal does not activate those species or settle future species-row aliases. If a species-specific row is later justified, its broad-name overlap must be projected alongside the generic group rather than treated as a replacement for it.

The active scope review found no cockle task limited to a branded-product, product-line, flavour, SKU, or retailer-variant roster. No such roster is researched or proposed here. Existing named product pages are used only for the fact that the generic plural market wording appears without a species identification; their product state, quantities, and other claims are not generalized.
