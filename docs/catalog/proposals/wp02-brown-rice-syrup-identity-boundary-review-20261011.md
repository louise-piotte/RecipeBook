# WP02 Section C — brown rice syrup identity-boundary review

- **Reviewed:** 2026-10-11
- **Status:** proposal only. This review changed only this proposal file; it made no changes to the canonical catalog, ledger, checklist, roadmap, tests, code, recipes, or generated artifacts.
- **Scope:** decide whether brown rice syrup is a food identity or an alias/form of generic rice syrup, malt syrup, glucose syrup, or a fermented rice product; review Québec French naming, recipe demand, exact-query behavior, measures, yield, and substitutions.
- **Plan item:** `docs/RecipeBook-global-ingredient-catalog-plan.txt`, Section C, lines 1389–90. The combined syrup checklist remains open and names malt syrup and rice syrup.

## Recommendation

Treat **brown rice syrup / sirop de riz brun** as a distinct, source-named sweetener identity. Reconcile the existing legacy candidate `ingredient-ref-brown-rice-syrup` if the coordinator accepts the search behavior described below. Keep the generic term **rice syrup / sirop de riz** unresolved: do not make it an alias for brown rice syrup and do not create a generic row from this evidence alone. Keep **malt syrup**, **glucose syrup**, **rice syrup solids**, and fermented rice foods separate.

The identity boundary is a culinary product name for a concentrated sweet syrup made from brown rice through starch saccharification [S04, S08, S11]. Manufacturer products show that ingredient declarations and process aids vary: one retail product lists brown rice and water, a clarified brewer's extract is described as brown rice and water, and a home recipe uses malted wheat [S03–S05, S08]. There is no Canadian compositional definition for “brown rice syrup” in the reviewed standards, so this recommendation is an ingredient-name boundary, not a legal classification or a claim that all products have one composition.

**Search caveat for integration:** the current ingredient search treats a complete word phrase inside a display name or alias as a match. If the proposed brown rice syrup reference becomes active, searches for unqualified `rice syrup` and `sirop de riz` will return it because those phrases occur inside the bilingual display names. No alias choice can prevent that while the display names remain `brown rice syrup` / `sirop de riz brun`. Decide whether that narrower result is acceptable for a generic query; if not, hold activation until the search/identity policy resolves the ambiguity. This review makes no code proposal.
