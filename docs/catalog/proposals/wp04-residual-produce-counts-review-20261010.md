# WP04 Proposal: Residual Produce Count Review

**Review date:** 2026-10-10  
**Status:** Proposal-only source review. Two exact, recipe-specific portion observations are proposed; all other residual count demands remain unsupported. No canonical data or recipe is changed.

## Scope and disposition

This review advances the remaining produce/herb count rows from the 44-row WP04/WP12 screen. I rechecked the exact ingredient text, stored amount/unit, reference ID, and recipe instructions in the live bundled recipes. Two official USDA SR28 records provide exact raw-pepper portions that the earlier screen had not verified: one jalapeño and one serrano. Recommend recording only these as source-specific `count_weight` / `published_portion` evidence. They do not support an active count conversion, default density, recipe edit, or weight for a cooked pepper.

The other 27 residual rows stay held for line-specific size, variety, state, edible-basis, or package gaps. In particular, the 2015 CNF large-onion, small-carrot, and large red-ripe tomato values remain provisional under the existing WP04/WP12 review. The prior CNF 2026 retrieval check found the official files inaccessible; this review did not repeat that attempt because no new access path was identified. An unreadable 2026 row is not evidence that the portion is absent.
