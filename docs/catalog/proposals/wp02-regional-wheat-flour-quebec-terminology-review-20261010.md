# WP02 Québec French terminology review: regional wheat-flour classes

**Review date:** 2026-10-10  
**Disposition:** Independent terminology review only. No catalog, ledger, roadmap, plan, code, or test files were changed.  
**Scope:** The ten Italian and French wheat-flour class references currently in the bundled catalog, their French/English names and aliases, and normalized name/alias searches across the live 691-reference file. No class crosswalks or equivalences are inferred.

## Findings

The common French construction **farine de blé tendre** is supported by the OQLF for *soft wheat flour*. The numbered formulations in these ten rows are transparent descriptive constructions; I found no OQLF or TERMIUM entry defining the Italian or French numeric classes. Quebec and Canadian product sources do attest a subset of the wording, including Quebec-made products marketed as **farine à pizza Tipo « 00 »**, **farine de blé T55**, and **farine de blé T65**. These product labels attest local language, but do not establish that the product class is identical to an Italian or French national class.

### Alias-field correction note

For all four Italian entries, the full `farina di grano tenero tipo N` string is Italian and appears in both `aliasesFr` and `aliasesEn`. It is useful for lookup, but it is not a Québec French or English term and the arrays duplicate the same normalized term within one record. Keep at most one copy in the project’s intended multilingual-search field; do not label it as French.

The `farine à pizza Tipo « 00 »` wording is genuinely attested in Quebec, including the La Milanaise product name. Its scope is a particular pizza flour product/use. The generic type-00 identity may retain it as a lookup phrase only if the catalog deliberately allows a narrower product phrase to find a regional class record. That retention does not establish that all Italian type-00 flours are pizza flours.

## Current 691-reference collision and query audit

Snapshot: `ingredient-references.v1.json` contains **691 references** and has SHA-256 `5922d0d6ab39f7954cf893193d74d7e6a72c51b2a48802c27b36f13a1c7bfe49`.

I normalized the ten references’ display names and aliases against all 691 active reference names and aliases using the same operations as `normalizeIngredientSearchKey` in [IngredientSearch.kt](../../../app/src/main/java/app/recipebook/domain/localization/IngredientSearch.kt): lowercase, Unicode NFKD, fold `œ`/`æ`/`ß` and `&`, remove combining marks, then convert non-alphanumeric runs to spaces and collapse whitespace. I also simulated the index’s complete-phrase matching over all 691 references.

- **Zero exact normalized cross-reference collisions** were found for any of the selected names or aliases. Every full display/alias phrase returns only its owning record in the 691-reference snapshot.
- `tipo 0`, `tipo 00`, `tipo 1`, and `tipo 2` each return their one matching Italian record. The broader query `tipo` returns all four Italian records; `Italian type` does the same.
- `farine de blé tendre`, `blé tendre`, and `farine de type` return all ten selected regional-class records. This is a broad family query, not an exact alias collision.
- `farine de blé` returns 16 records, including the ten regional classes plus durum flour, malted wheat flour, roasted wheat flour, wheat meal, whole-wheat flour, and whole-wheat pastry flour. Bare `farine` returns 58 records.
- `farine T55` / `T55` and `farine T65` / `T65` each return one record: the France-class entry. The query is internally unique, but the Quebec products cited above use the same short label. A unique picker result therefore must not be read as evidence that the locally marketed flour and the France class have the same definition.
- The target ten have no attached ingredient-form records, so no selected form label contributed to these results.

## Search limits

The OQLF and TERMIUM searches were for the base wheat-flour terms and the exact Italian/French class strings (`tipo 00`, `tipo 0`, `tipo 1`, `tipo 2`, `T45`, `T55`, `T65`, `T80`, `T110`, `T150`). The positive OQLF/TERMIUM evidence supports the base wording only. A search-result absence is not proof that a term is never used. Product wording demonstrates attestation in the cited product context; it does not establish a national standard, legal status, equivalence, or interchangeability. The review does not assign ash, extraction, protein, use, geographic-origin or crosswalk claims to the catalog references.
