# WP04 Count, Edible-Portion, and Composition Fixture Gap Review

**Review date:** 2026-10-11  
**Status:** Proposal only. No shared data, plan, roadmap, code, or test files changed.

## Conclusion

The 114-recipe audit closed the bounded candidate search. It did not close the WP04 fixture deliverable. The current Python package tests already cover most reviewed evidence decisions, including exact count matches, source-qualifier mismatches, count-only outcomes, and the main package cases. Repeating those ledger assertions would add little coverage.

The remaining test gap is the connection to app behavior. Kotlin tests do not load a real bundled count ingredient and prove that a source-only portion stays unavailable as a count-to-mass conversion. Existing count UI tests use a hand-authored `30 g per large egg white` mapping. That value is a mechanics fixture, not an accepted WP04 observation. Add an actual-catalog negative case alongside it. Add corpus regression cases for the three unresolved package rows, the ground-turkey source-version mismatch, and the recipe-local composition choices.

No test in this matrix should create a new measurement, conversion, package size, edible yield, or fat percentage. The exact recipe amounts and existing ledger observations remain the only numeric fixtures.

- `015#4`, `089#3`, and `098#1` remain source and package-content gaps. Their fixture is a negative availability case; it must not contain an expected gram or millilitre amount.
- `018#1` is a source-version mismatch. The current publisher card is not evidence for rewriting the saved household import.
- `078#3` has an exact current publisher line, but it supplies recipe wording and an alternative, not a branded product label or verified numeric composition.
- `026#3` is already matched to the current official Eagle Brand recipe. The Original/Low Fat wording does not quantify fat or identify which alternative was selected.
- `105#3`, `105#6`, `028#7`, `067#8`, `077#5`, and `104#1` are already covered data-level cases. Keep their different source bases distinct; add app-level tests only where they verify real bundled data does not acquire a conversion.

## Primary-source checks

- Health Canada’s [CNF serving page for raw carrots, food code 2380](https://food-nutrition.canada.ca/cnf-fce/serving-portion?id=2380) currently lists `1 small (14 cm long) = 50 g` and an 11% refuse entry. This is a size-qualified raw-food portion. It does not establish that every recipe phrase “small carrot” has that length. The 2026 CSV integration remains separately documented by its joined food/measure codes and SHA-256 values in the batch README above.
- Health Canada’s [CNF egg pages for whole eggs, whites, and yolks](https://food-nutrition.canada.ca/cnf-fce/serving-portion?id=125), [code 126](https://food-nutrition.canada.ca/cnf-fce/serving-portion?id=126), and [code 127](https://food-nutrition.canada.ca/cnf-fce/serving-portion?id=127) publish source-specific raw portions, including a large raw white at 33 g. The official [FoodData Central Foundation search](https://fdc.nal.usda.gov/food-search/?query=eggs&type=Foundation) labels its egg items Grade A, Large; its current [Foundation Foods documentation](https://fdc.nal.usda.gov/docs/Foundation_Foods_Documentation_Apr2024.pdf) describes portions as edible material without refuse. These sources preserve distinct market, food-state, and part qualifiers. They do not establish an active app conversion for every large egg white.
- USDA ARS [SR28 NDB 09328](https://www.ars.usda.gov/ARSUserFiles/80400535/Data/SR/SR28/reports/sr28fg09.pdf#page=526) is explicitly *Maraschino cherries, canned, drained*. The drained condition is part of the portion identity and matches only the drained recipe line.
- The linked publisher’s current [Shepherd’s Pie card](https://www.thewholesomedish.com/the-best-classic-shepherds-pie/) contains `1 lb. 90% lean ground beef -or ground lamb`. The [CFIA standard](https://inspection.canada.ca/en/about-cfia/acts-and-regulations/list-acts-and-regulations/documents-incorporated-reference/canadian-food-compositional-standards-0) defines Canadian Lean Ground Beef as a product class with a maximum fat limit. That class is not a numeric reading of the publisher’s phrase and must not be substituted into the fixture.
- The current [Preppy Kitchen Turkey Meatballs card](https://preppykitchen.com/turkey-meatballs/) is marked updated March 25, 2023, lists one pound of ground turkey, and says any type can be used. The local `018#1` row is two pounds of lean ground turkey. No matching version was found in the reviewed evidence.
- The current [Eagle Brand Magic Cookie Bars card](https://www.eaglebrand.ca/en/recipes/bars-and-cookies/magic-cookie-bars) states one 300 mL can of Original or Low Fat sweetened condensed milk. It supports the exact recipe volume and alternatives, not a numeric fat value or mass yield.
