# WP03 Section F Ethiopian Beso/Besso product-boundary hold — 2026-10-13

Integrated the [round-66 Beso/Besso review](../../proposals/wp03-section-f-ethiopian-beso-product-boundary-hold-20261013-r66.md).

## Decision

Keep Beso/Besso unallocated. Ethiopian field and preparation sources describe roasted barley flour,
variable processing, wet preparations, and a cereal-flour name that also appears in a maize-based
formulation. Retail evidence establishes both a formulated roasted-barley blend and one plain,
single-ingredient roasted-barley-flour product sold as Beso. That confirms a real plain-flour use,
but it does not establish that unqualified Beso/Besso consistently means that product or provide a
Québec French Beso/Besso product name.

Do not add the bare terms or qualified flour phrases to the existing roasted-barley-flour aliases,
create a standalone reference, or add a ledger candidate. Keep Beso separate from bsissa and other
roasted-grain products. The bundled corpus has no matching recipe demand. Package weights,
preparation formulas, and clinical prepared-serving amounts do not establish a reusable measure,
density, conversion, or substitution.

No catalog or research-ledger data changed. The proposal records the source evidence, current search
ownership, and conditions for reopening the decision.

## Checks

- Read-only reference, form, legacy, ledger, archive, and recipe searches found no existing Beso/Besso allocation or recipe demand.
- Current phrase-first search projection shows that assigning Beso to the existing roasted-barley-flour row would make the unqualified term resolve to that row alone.
- No app tests or emulator checks were run; this is a documentation-only hold.

Section F remains open.
