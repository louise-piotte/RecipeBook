# WP03 Section K R126 — corn-husk wrapper identity integration

Added identity-only corn husks / enveloppes de maïs as a culinary wrapping plant part, separate from corn kernels and ears and from banana leaves. Search aliases are limited to corn husk, enveloppe de maïs, feuille de maïs, and feuilles de maïs. The reference uses the internal VEGETABLE_AND_AROMATIC category; this does not claim that the wrapper is eaten.

Added one dried form under the identity, with English and French labels and narrow dried-state match terms. New Mexico State University Cooperative Extension documents dried corn husks and soaking before use; its one-pound quantity and approximate six-dozen yield remain specific to that recipe. The review found no Québec or Canadian retail listing for dried husks, so this form record does not claim local inventory. No density, unit mapping, count, fresh-to-dried conversion, yield conversion, recipe link, or substitution was added.

Marché Andes in Montréal distinguishes corn-leaf tamales from banana-leaf tamales. Quesada and RICARDO support the French wording enveloppes de maïs and feuilles de maïs; the RICARDO recipe is labeled advertising content and is used only as one source-specific example. The 114-recipe / 1,123-row bundle has no corn-husk or tamale demand.

Four external sources, S01–S04, are attached to the ingredient identity. The dried-form record reuses S01, S03, and S04 for its state and label boundary. Static package validation, reference normalization, generated-index freshness, picker projections, corpus scan, source-ID ownership, UTF-8/no-BOM, local-link, and whitespace checks passed. At integration, the catalog contained 1,474 references, 106 forms, 1,816 ledger records, 7,513 source entries, and 6,388 distinct source IDs.

No app, Gradle, unit, instrumentation, emulator, or deployment tests were run because the change only adds database JSON data under the updated AGENTS.md rule.
