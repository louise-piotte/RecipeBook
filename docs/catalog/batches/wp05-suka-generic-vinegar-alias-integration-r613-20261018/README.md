# Generic Filipino `suka` alias — 2026-10-18

Added `suka` to the English and French search-alias arrays of generic `vinegar / vinaigre`. Philippine Department of Agriculture sources use `suka` for generic vinegar. This keeps a search for `suka` from returning only Suka Pinakurat: the exact query now returns the generic vinegar identity and the product-specific row.

No recipe links, forms, measurements, conversions, yields, or substitutions were added. No tests were run because this only adds database JSON data under `AGENTS.md`.
