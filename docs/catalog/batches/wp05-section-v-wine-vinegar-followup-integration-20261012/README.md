# WP05 Section V — wine and sherry vinegar

**Integration date:** 2026-10-12  
**Status:** identity-only integration; Section V remains open.

## Changes

- Added `ingredient-ref-wine-vinegar` as `wine vinegar / vinaigre de vin`, with no aliases. It represents the broad standard class made from wine, not an alias for red- or white-wine vinegar.
- Added `ingredient-ref-sherry-vinegar` as `sherry vinegar / vinaigre de Xérès`, with no aliases. It remains distinct from generic wine vinegar and from the protected regional designation `Vinagre de Jerez`.
- Kept fruit-flavoured and fruit-source vinegars, maple vinegar, and unqualified palm vinegar unresolved; the reviewed product wording does not establish one broad identity across those products.
- The 114-recipe / 1,123-row audit found no wine-vinegar or sherry-vinegar line. Existing generic vinegar and white-vinegar rows remain unchanged. No recipe links, forms, measures, conversions, preservation guidance, or substitutions were added.
