# WP03 Section I ginkgo seed handling hold

Reviewed ginkgo seed/kernel as a distinct food-use candidate for Ginkgo biloba. Kept it outside the active catalog because the available sources do not establish a source-neutral preparation boundary that the current schema can represent, and the Canadian grocery listings do not establish a Québec French food name. This is a catalog-readiness hold, not a finding that ginkgo seeds lack food use.

No active reference, ledger candidate, alias, form, measure, recipe link, or substitution was added. The bundled recipe corpus has no matching demand. This documentation-only hold required no tests.
