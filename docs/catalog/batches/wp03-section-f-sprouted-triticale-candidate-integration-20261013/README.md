## Decision

Recorded `candidate-sprouted-triticale-grain` as `needs_clarification` in the research ledger. Puratos Canada's current Softgrain Treize ingredient list names sprouted triticale grains as one component in a 13-grain-and-seed bakery blend. The product description says Softgrain grains are cooked and infused with sourdough; its 16.5 kg bucket describes the complete blend. Neither page establishes a standalone triticale ingredient, the component's quantity or state, or a household product.

The French page calls the blend's four components `grains germés` but leaves `Sprouted triticale grains` in English. OQLF and Usito support the base term `triticale`; Canadian Grain Commission grading language and a Québec bread label name different contexts (`grains germés` as a grading factor and `triticale concassé` for cracked triticale). No French compound was promoted to an active name or alias.

## Catalog and recipe limits

Keep the existing triticale grain, flakes, and flour references separate. The candidate is ledger-only: no active reference, form, alias, recipe link, measure, density, unit mapping, conversion, yield, or substitution was added. The 114-recipe / 1,123-row corpus has no matching demand.

During root review, the proposal's original `WP03-S79` label was found to be misattributed. That existing ledger source is Usito, not OQLF. The proposal and candidate record now label it correctly and use `WP03-SPROUTED-TRITICALE-20261013-R59-S04` for the separate OQLF entry.
