# Saffron identity integration

Promoted the exact legacy candidate `ingredient-ref-saffron` to identity-only `saffron / safran` in `BAKING_AND_SPICE`. OQLF supports the Québec French and English terms and identifies saffron's spice use. A Québec grocery listing confirms a Spanish saffron-filament product; its 1 g package size remains product-specific.

The active catalog has no recipe demand for saffron. No aliases, forms, recipe links, measures, density, unit mappings, conversions, yields, or substitutions were added. The legacy candidate was removed after promotion; the ledger record now tracks the accepted identity and blocked reusable numeric/substitution evidence.

Sources and decisions are recorded on `ingredient-ref-saffron` in the research ledger. See [OQLF's *safran* entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/2095427/safran) and [Super C's saffron-filament listing](https://www.superc.ca/allees/garde-manger/fines-herbes-epices-et-sauces/epices/filaments-de-safran-espagnol/p/059749961349).
