# WP04 Section P: Atlantic croaker picker hold

Root accepted the hold for Atlantic croaker, *Micropogonias undulatus*. CFIA lists the bare English common name `Croaker` for this and multiple other fish taxa, including *Micropogonias furnieri*. The current picker has no generic croaker result; adding the qualified display `Atlantic croaker / tambour brésilien` would make a `croaker` query return only this species.

OQLF supports `tambour brésilien` as the preferred Québec edible-fish term and pairs it with English `Atlantic croaker` and *M. undulatus*. Its commercial-potential note does not establish current Québec inventory. The full 114-recipe / 1,123-row bundle has no candidate phrase hits. Health Canada's Canadian Nutrient File has a raw *M. undulatus* record with source-specific fillet and Food Guide portions; because the identity is held, none of those values is active catalog data.

No reference, ledger record, alias, form, measurement, density, mapping, conversion, yield, recipe link, or substitution was added. Revisit when picker behavior can represent the broader croaker scope without returning one species alone.

This documentation-only hold required no app tests or emulator checks. Section P remains open.
