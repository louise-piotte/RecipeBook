# WP03 Section J R1021 — generic ramps identity

- **Date:** 2026-10-19.
- **Status:** Integrated.
- **Identity:** Added `ramps / ail trilobé` as an identity-only `VEGETABLE_AND_AROMATIC` reference for *Allium tricoccum*.

The OQLF entry directly pairs *A. tricoccum* with `ail trilobé` and English `ramps`; NCSU Extension lists the leaves, stems, and bulbs as edible parts. Keep the reference separate from *A. ursinum*, generic leek and green onion, garlic, chives, and other wild alliums. Omit `wild leek`, `ramson`, `spring onion`, and `ail des bois` aliases because they overlap nearby picker boundaries. The sources do not establish a household measure, form mapping, yield, or recipe substitution. The OQLF collection/trade note and NCSU look-alike notes were not converted into legal, harvesting, identification, or safety guidance.

The existing Food Code observations for green onion and leek remain on their current references. The manifest-listed recipe corpus contains no ramps or *Allium tricoccum* demand. No forms, recipe links, measurement observations, active substitutions, conversions, or yields were added.

No brand, product-line, flavour-family, SKU, or retailer-variant roster was pursued. Existing branded entries and product-specific evidence remain intact; commercial-product counts do not add ingredient diversity.
