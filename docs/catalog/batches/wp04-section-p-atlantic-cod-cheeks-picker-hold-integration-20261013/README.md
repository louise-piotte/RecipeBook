# WP04 Section P Atlantic cod cheeks picker hold — 2026-10-13

Integrated the [round-65 cod-cheeks review](../../proposals/wp04-section-p-atlantic-cod-cheeks-cut-form-boundary-review-20261013-round65.md).

## Decision

Keep Atlantic cod cheeks outside active references, forms, and the research ledger. Canadian seafood
sources document cod cheeks as a food product, and Québec sources support `joue(s) de morue` naming.
OQLF applies `joue / cheek` across morue, flétan, baudroie, and raie. Under current phrase-first
search, one Atlantic-cod form would make broad `cheek(s)` and `joue(s)` queries return Atlantic cod
alone. The bundled recipes contain no cheek or cod demand.

No species or cut was added, and no density, portion, yield, conversion, recipe link, or substitution
was inferred. If recipe demand appears, revisit only with a search result set that preserves the
broader species choice or with independently supported choices for the other Québec-named species.

No catalog or research-ledger data changed. The proposal records the source register, current search
projection, and product/taxon limits.

## Checks

- Read-only reference, form, ledger, archive, and recipe audits found no existing cod-cheek allocation or recipe demand.
- Current `IngredientSearch` matching confirms that form labels and match terms participate in phrase-first search and substring fallback.
- No app tests or emulator checks were run; this is a documentation-only hold.

Section P remains open.
