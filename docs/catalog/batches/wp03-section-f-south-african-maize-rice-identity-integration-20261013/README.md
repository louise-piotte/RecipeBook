# WP03 Section F South African maize rice identity

Added identity-only `ingredient-ref-south-african-maize-rice` as `maize rice / maize rice` in `GRAIN_AND_CEREAL`, with the source-attested English alias `mealie rice`. South African grading regulations distinguish it from samp, maize grits, and maize flour; current Botselo and Woolworths listings confirm the product. Keep the French display provisional pending Québec review, with no French aliases. Do not add `riz de maïs` or `semoule de maïs`; the latter remains with cornmeal.

The recipe bundle has no matching maize-rice demand. Package sizes and sieve criteria are not household measures. No forms, density, unit mappings, recipe links, conversions, yields, or substitutions were added. No app tests or emulator checks were run because this change only adds database JSON data.

The proposal snapshot after R54 contained 1,379 references and 1,709 ledger records. This integration brings the current package to 1,380 references and 1,710 records; forms, legacy candidates, recipes, and recipe-line counts are unchanged.
