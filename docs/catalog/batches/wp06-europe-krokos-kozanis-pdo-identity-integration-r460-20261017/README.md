# R460 — Krokos Kozanis PDO saffron integration

Added identity-only **Krokos Kozanis PDO saffron / safran Krokos Kozanis AOP** as a regional identity beside generic saffron. The only alias is the Canadian retailer title **Krokos Kozani Saffron**. Generic Greek saffron wording remains unassigned, and no forms were added because a regional-only powder or filament form would make broad saffron-form searches point to one PDO origin.

The European Commission confirms the protected origin and its regional production boundary. The official French page uses **Krokos Kozanis AOP**, while a current Canadian French campaign uses **safran Krokos Kozanis AOP**. The Canadian product pages support narrow market wording but do not establish current availability or Québec stock.

No bundled recipe row needs the reference. PDO package sizes and retailer package quantities remain source-specific. No form, reusable measure, density, unit mapping, conversion, yield, recipe link, or substitution was added. Measurement research found no reusable value; substitution research remains not yet researched.

Static package normalization, generated-index freshness, ledger-schema validation, source ownership, corpus matching, UTF-8/no-BOM, and scoped whitespace checks passed. No app or Android tests were run for this database-JSON addition under `AGENTS.md`.
