# WP04 Section P R584 — Zander identity integration

Added identity-only `ingredient-ref-zander` for *Sander lucioperca* as **pike-perch / sandre européen**, with English alias **zander** and French alias **doré européen**. The CFIA Fish List separately assigns this species its qualified names and distinguishes it from Walleye (*S. vitreus*) and Sauger (*S. canadensis*). Bare `European walleye` and `European pickerel` were not added as aliases; the latter would make bare `pickerel` return Zander alone.

The reviewed retailers identify the fish but their quantities remain product-specific. Metro’s French product **229351** is titled `Filet de doré européen décongelé` and reports about four fillets per tray, with no tray mass. Metro and Super C’s English product **235617** is titled `Previously frozen European pickerel fillet`; Metro shows a 200 g to 800 g serving selector, while Super C reports 400 g average. The product numbers differ between the French and English Metro pages, so they are not treated as paired bilingual listings or as shared measures. The checked pages reported out of stock. No CNF 2026 food code or portion for this species was verified.

The active picker now returns Zander for `zander`, `pike-perch`, `sandre européen`, `sandre`, and `doré européen`. `doré` returns five references, `pike` returns two, and `perch` returns four; each remains multi-result. `pickerel` and `European pickerel` still return no result, while `walleye` and `doré jaune` still return only Walleye.

The full bundled corpus contains 114 manifest-listed recipes and 1,123 ingredient rows. Candidate and species-qualified search terms had no recipe matches. The broad word `doré` occurs in nine recipe files, but in no ingredient rows. No form, density, unit mapping, reusable measure, package yield, conversion, recipe link, or substitution was added.
