# WP06 African regional R515 — Oha leaves integration

Integrated identity-only `oha leaves / feuilles d’oha` as `ingredient-ref-oha-leaves` in `VEGETABLE_AND_AROMATIC`. Added only the singular English alias `oha leaf` and the retailer phrase `oha feuille` as a French search alias. The French display remains provisional; the French alias records Toronto marketplace wording and is not presented as standardized Québec terminology.

The identity is bounded to Oha leaves used as a Southern Nigerian soup vegetable. A Nigerian food study identifies the leaves as *Pterocarpus mildbraedii*; Kew accepts the species. Canadian sellers support the English retail wording, and one Toronto listing supplies `Oha Feuille`. The spelling `Ora` remains research evidence because adding it would collide with unrelated picker results. Prepared dishes, *Uha*, scientific-name wording, and other soup leaves remain separate.

Added six source entries to the research ledger. No recipe demand appeared in the 114 manifest recipes / 1,123 ingredient rows. No forms, measurements, conversions, yields, recipe links, or substitutions were added. The six Canadian retail package weights remain SKU information only.

Static package and research-ledger validation passed, and the generated ingredient index is current. Picker projection, source-ID/URL ownership, UTF-8/no-BOM and escaped-seed-Unicode checks passed. Per `AGENTS.md`, no software tests, builds, emulator checks, or deployment were needed for this database-data addition.

Post-integration snapshot: **1,788 references / 143 forms / 56 legacy candidates; 2,145 ledger records / 9,846 source entries / 8,333 distinct source IDs / 7,043 distinct URLs**. Broader African regional coverage remains open.
