# WP04 Section P smoked-eel identity integration (R187)

Added identity-only smoked eel / anguille fumée as ingredient-ref-smoked-eel in PROTEIN. The
reference represents a species-neutral finished-food market group. It remains separate from
American eel / anguille, the unresolved broad-eel identity candidate, and the R175 unagi/kabayaki
boundary.

Québec market evidence supports both English and French smoked-eel wording, including the Les
Saveurs du Bas-Saint-Laurent product, Frandon's bilingual supplier listings, and the Fumoir
St-Antoine menu. The CFIA Fish List and OQLF evidence remain attached as boundary sources: they
show why the new market group does not identify a species or become a form under American eel.
Capone's indexed listing remains SKU-specific and is marked as such in the proposal.

Added one reference and one ledger record. The ledger record has eight source entries, including
four new market URLs and four reused sources. It records no supported reusable measure or
substitution. No aliases, forms, density, mappings, measurements, recipe links, conversions,
yields, or substitutions were added. The 114-recipe / 1,123-row corpus has no matching demand.

Static seed-package, reference-normalization, generated-index, ledger/source, picker, recipe-corpus,
UTF-8/no-BOM, escaped-Unicode, local-link, and scoped whitespace checks passed. Totals after
integration: 1,568 references, 122 forms, 1,913 ledger records / 8,233 source entries / 7,028
distinct source IDs / 5,822 URLs; 114 recipes / 1,123 ingredient rows. No software tests were run
because this change only adds database JSON data under AGENTS.md.
