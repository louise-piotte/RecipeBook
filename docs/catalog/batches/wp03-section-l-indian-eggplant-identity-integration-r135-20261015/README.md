# WP03 Section L R135 — Indian eggplant identity

## Decision

Added identity-only Indian eggplant / aubergine indienne, grounded in Canadian retail listings and a Montréal produce catalogue. The row makes no species or cultivar claim and has no aliases. Canonical singular phrases identify the product; no plural aliases were added because the picker does not singularize and Indian-only plurals would also make bare plural searches resolve to this row.

Walmart's 0.03–0.11 kg single-item range and Atlantic Superstore's 0.1 kg average remain separate listing-scoped ledger observations. Metro's 60 g quantity is an approximate pricing basis, not an item-weight observation. No reusable measure, density, mapping, form, or recipe link was added.

The Bagara Baingan recipe's large-globe fallback is recorded as a dish-scoped finding with no replacement amount. No bundled recipe demand was found; no active substitution rule was added.

Static package normalization, reference normalization, generated-index freshness, ledger/schema, picker projection, source-ID, UTF-8/no-BOM, local-link, and whitespace checks passed. No app tests were run because this change only adds database JSON data and refreshes the generated reference index, under the AGENTS.md exception.
