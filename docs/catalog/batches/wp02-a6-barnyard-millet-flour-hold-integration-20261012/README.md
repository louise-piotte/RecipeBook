# WP02 A6 — barnyard millet flour naming hold (2026-10-12)

## Decision

Keep barnyard millet flour as an unallocated A6 candidate. A current Ontario retailer lists the exact
English product name, but its listing does not state the source grain or French wording. Québec food
product and terminology sources support generic `farine de millet`, not a barnyard-specific display.

Do not create `ingredient-ref-barnyard-millet-flour`, alias it to `ingredient-ref-millet-flour`, or
invent a French compound. Keep `millet japonais` inactive: FAO associates the French name with
*Echinochloa esculenta*, while a Québec vineyard cover-crop guide uses it for *E. frumentacea*. These
sources do not establish a Québec human-food name or the species in the Canadian flour listing.

The review proposal contains the full source register and exact-key/recipe audits:
[WP02 A6 barnyard millet flour naming review](../../proposals/wp02-a6-barnyard-millet-flour-naming-review-20261012.md).

## Evidence checked

- [Indian Grocery Store S&V millet collection](https://indiangrocerystore.ca/collections/s-v-millets) lists S&V Barnyard Millet Flour; the listing does not disclose species or French wording.
- [Québec Food Directory Cuisine Soleil product](https://www.repertoirealimentsquebecois.gouv.qc.ca/Produit/Index/8223769) uses generic `Farine de Millet Biologique` and supplies no species.
- [OQLF millet entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/26506455/millet) describes `millet` as a generic term across species.
- [FAO French millet reference](https://www.fao.org/millets-2023/about/fr) names *E. esculenta* `millet japonais`; [AgriRéseau's Québec vineyard cover guide](https://www.agrireseau.net/documents/Document_109377.pdf) uses the name for *E. frumentacea*. These are differing taxon associations, not Québec food labels.
