# WP04 Section P generic fish-powder boundary hold (R190)

Kept generic `fish powder / poudre de poisson` unallocated. Current Canadian and Québec retail pages
support those product titles, and a marketplace seller describes its Mangne product as dried fish,
finely ground for seasoning. Other unqualified listings omit species, ingredients, and process, so
the reviewed sources do not establish one common product boundary. Keep Bonga powder, anchovy
powder, fish-stock blends, and feed-grade fish meal separate. The supported French retail phrase is
not an OQLF food-product headword.
