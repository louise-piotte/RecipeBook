# WP02 Section A7 R451 wheat-groats hold

Recorded on 2026-10-17 after root review of the [R451 proposal](../../proposals/wp02-section-a7-wheat-groats-product-boundary-review-r451-20261017.md).

## Decision

Keep the named France-market Dzedzaz wheat-groats product unallocated. The supplier describes removal of an outer covering but does not establish whether the kernel stays whole, whether bran and germ remain, or how the product differs from its nearby Hadig whole-wheat item. No current Canadian or Québec product source verifies Dzedzaz or establishes `gruau de blé` as a Québec name for it.

Preserve the existing wheat-berries, cracked-wheat, bulgur, wheat-meal, wheat-grits, wheat-semolina, and hot-cereal identities and holds. Do not add a Dzedzaz or wheat-groats row, alias, ledger candidate, form, measurement, density, mapping, conversion, yield, recipe link, or substitution. The complete 114-recipe / 1,123-row bundle has no matching ingredient demand.

## Scope and verification

- This decision changes only the catalog plan, roadmap, and review archive. No database JSON, generated index, recipe, or application file changed.
- The review used an earlier same-day catalog snapshot, before R449 and R450 were integrated. Its snapshot hashes and counts are preserved in the proposal as a historical audit point.
- The proposal records the distinction between the France-market Haudecoeur/Legumor product, Canadian grain terminology, and Québec `gruau` usage, with the source limits and picker projection.
- No tests, build, emulator check, or deployment were needed for this documentation-only hold.

Section A7 remains open. Reopen this candidate when a current Canadian/Québec product or authoritative terminology source establishes both a product-state boundary and a suitable French name.
