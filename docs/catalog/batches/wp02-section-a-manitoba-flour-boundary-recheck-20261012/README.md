# WP02 Section A Manitoba flour boundary recheck — 2026-10-12

The earlier [white-wheat and Québec flour-terminology review](../../proposals/wp02-wheat-flour-quebec-identity-gap-review-20261010.md)
held `Manitoba` / `farine Manitoba` as product-level wording. This follow-up checked current
Montréal listings before closing that candidate review in the Section A checklist.

## Decision

Keep `Manitoba` outside the active ingredient catalog as a generic regional flour identity and do
not alias it to Italian type 0, Italian type 00, high-gluten flour, bread flour, or all-purpose
flour. A Montréal retailer currently lists one Vecchio Molino product named `Farine Manitoba` and
describes it as enriched, unbleached type 00 flour. The same retailer lists Caputo `Farine Manitoba
Or` as type 0 and describes that product as strong, high-protein flour. The shared market label
therefore does not identify one national milling class or one product specification in these
examples. Their use descriptions remain specific to each product.

Keep future product-level `Manitoba` terms searchable only when a source establishes a bounded
product identity. Reopen a generic class only if a primary standard or consistent miller evidence
defines its wheat/milling scope and independent Québec French evidence supports a stable display.

No ingredient reference, alias, ledger candidate, recipe link, measurement, conversion, or
substitution changed. The earlier recipe-corpus review found no bundled demand for Manitoba flour.
This documentation-only checklist update required no tests or emulator checks.

## Current product sources

- Berchicci, Montréal, [Vecchio Molino Farine Manitoba 1 kg](https://store.berchicci.ca/fr-ca/Vecchio-Molino-Manitoba-Farine): the product title uses `Farine Manitoba`; the description calls it enriched, unbleached type 00 soft-wheat flour (accessed 2026-10-12).
- Berchicci, Montréal, [Caputo Farine Manitoba Or Blé Tendre '0' 5 kg](https://store.berchicci.ca/fr-ca/Caputo-Farine-Manitoba-Or-Bl%C3%A9-Tendre-5): the product title specifies type 0; the description calls it strong flour made from high-protein wheat (accessed 2026-10-12).

These are retailer listings for named imported products, not official grade definitions or evidence
of universal Canadian availability.
