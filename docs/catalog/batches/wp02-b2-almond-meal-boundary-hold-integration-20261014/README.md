# WP02 B2: almond-meal boundary hold

The R114 review keeps generic `almond meal` unassigned. Current Canadian and Québec product labels
do not establish one stable grind or skin-state boundary: the Québec Food Directory names a
blanched-ground product “Almond Meal / Ground Blanched Almonds”; Ameen labels a fine product almond
flour and lists almond meal as a product-specific synonym; Mayrand lists extra-fine almond meal; and
Nutterie uses `poudre d'amande naturelle` for a granular product. Nutterie's page showed the item
unavailable during review, so its wording is product evidence, not a stock claim. King Arthur's
interchangeability guidance is conditional on matching grind.

Root accepted the hold. Keep the ordinary almond-flour and separate defatted-almond-flour identities
unchanged. Do not add a generic almond-meal identity or alias, `ground almonds` alias, form, measure,
conversion, yield, recipe link, or substitution. The 114-recipe / 1,123-row corpus has two ordinary
almond-flour links and no almond-meal demand.

See the [R114 almond-meal product-boundary review](../../proposals/wp02-b2-almond-meal-product-boundary-review-r114-20261014.md).

integration changes documentation only; no tests or emulator checks were run.
