# WP04 Section P R97 — red grouper picker hold

Reviewed and recorded 2026-10-14. The broader Section P finfish and seafood sweep remains open.

## Decision

Held red grouper, *Epinephelus morio* (CFIA TSN 167702), outside the active catalog and research
ledger. CFIA lists `Red Grouper / Mérou nègre`, but also assigns the unqualified `Grouper / Mérou`
pair to this taxon and multiple other taxa. OQLF defines Québec `mérou / grouper` broadly for
Serranidae, especially *Epinephelus* and *Mycteroperca*. Under the current phrase-first picker, a
hypothetical `red grouper / mérou nègre` row would become the sole result for the broad `grouper` and
`mérou` queries.

The current Québec retailer pages use broad grouper wording without a binomial, and one retailer
reports all grouper temporarily withdrawn from its own inventory. This does not identify local
product species or establish a legal ban. The 114 bundled recipes contain no grouper demand. Keep the
candidate unallocated until search can preserve the broad alternatives or a source supplies a
species-qualified request and the Québec display is confirmed.

No reference, legacy candidate, ledger record, alias, form, measure, recipe link, conversion, yield,
or substitution was added. No app, Gradle, instrumentation, or emulator tests were run because this
is a documentation-only hold.

  lists grouper as temporarily withdrawn from Metro's inventory; this is seller-specific, not a
