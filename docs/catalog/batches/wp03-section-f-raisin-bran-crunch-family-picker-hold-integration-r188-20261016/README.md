# WP03 Section F Raisin Bran Crunch family-picker hold (R188)

Recorded a documentation-only hold for Kellogg's Two Scoops Raisin Bran Crunch Cereal /
Céréales Kellogg's Raisin Bran deux pelletées Croquantes. The Canadian manufacturer lists
standard Two Scoops Raisin Bran and Raisin Bran Crunch as distinct siblings in English and
French. Adding only Crunch would make broad Raisin Bran queries return one sibling.

The Provigo 1 cup (57 g) serving belongs to its exact 436 g SKU and stays outside active catalog
measurements while the family decision is held. The bundled corpus has no matching demand across
114 recipes and 1,123 ingredient rows. No catalog or ledger data changed.

The Section F checklist and roadmap now record the family hold. No software tests were run because
the change added no database JSON data. See the [R188 proposal](../../proposals/wp03-section-f-raisin-bran-crunch-family-picker-hold-review-r188-20261016.md)
for the source register, picker projection, product-specific serving boundary, and reopen conditions.
