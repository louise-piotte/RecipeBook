# WP02 Section 04 B2 `amidon aigre de manioc` naming hold (R202)

Integrated as a documentation-only hold. Keep `amidon aigre de manioc` outside the French aliases
for `ingredient-ref-brazil-polvilho-azedo` until current Québec product or terminology evidence
supports it. The phrase is directly paired with Brazilian `polvilho azedo` on a Canadian Pinduca
listing, but the listing was sold out and belongs to a Kingston, Ontario retailer. A current
Chambly, Québec product page uses the already accepted `farine de polvilho azedo` alias. OQLF's
`fécule de manioc` entry covers generic starch, not this fermented product wording. CIRAD/IRD
technical usage supports the phrase as product-related, not as local Québec consumer terminology.

Keep the existing displays, `farine de polvilho azedo` alias, generic tapioca-starch row, sweet
polvilho row, and measurement/substitution research states unchanged. No alias, form, active measure,
density, mapping, conversion, yield, recipe link, or substitution was added. The 114 manifest-listed
recipe files and 1,123 ingredient rows contain no matching phrase or linked polvilho ingredient.

The proposal records the exact-key audit and picker projection: adding the full phrase would enable
its direct query but would also expand broad `aigre`, `amidon`, and `manioc` searches. Reopen only
when a current Québec product/package listing or Québec terminology authority uses this wording for
a product clearly identified as Brazilian `polvilho azedo`.

No database JSON or generated catalog data changed, so no software tests or emulator checks were
needed. See the [R202 proposal](../../proposals/wp02-section-04-b2-polvilho-amidon-aigre-quebec-naming-review-r202-20261016.md)
for the source register and evidence limits.
