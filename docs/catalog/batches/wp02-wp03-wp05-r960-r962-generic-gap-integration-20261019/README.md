Kept it separate from raw oat germ, sprouted oat flour, oat bran/flour, and feed-grade fractions. Bread-study addition percentages remain study-specific; no replacement ratio or generic measure/density was activated.

No aliases, forms, recipe links, active substitutions, conversions, yields, reusable measures, or unit mappings were added. Existing catalog entries and evidence were not deleted, merged, or generalized.

Its bounded substitute search did not establish a matching dish role or replacement context.
