# WP03 — Polenta Taragna dry-mix hold (2026-10-12)

## Decision

Keep the packaged dry corn-and-buckwheat blend sold for polenta taragna out of the active catalog.
The product is distinct from cornmeal, buckwheat flour, and the prepared polenta taragna dish, but no
Québec French package name or terminology decision establishes its bilingual display. In the current
picker, an active name or alias containing `polenta taragna` would also match a bare `polenta` query,
making the narrow regional blend appear to be the unspecified product. The full manifest-listed bundle
has 0 matching terms across 114 recipes and 1,123 ingredient rows.

No active reference, alias, legacy candidate, research-ledger record, form, density, unit mapping,
measure, recipe link, conversion, yield, or substitution was added. Keep the generic-polenta hold and
the existing cornmeal and buckwheat-flour identities unchanged. The proposal records a possible later
ledger-only candidate record, but this review did not add one.
