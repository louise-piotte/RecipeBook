# Generic barley grain identity integration

Added identity-only `barley / orge` as `ingredient-ref-barley` in `GRAIN_AND_CEREAL`. The row has no aliases, attached forms, recipe links, reusable numeric data, or substitutions. Existing qualified barley products remain separate. Canadian Grain Commission sources distinguish food barley from malting and general-purpose classes and recognize different covered and hulless kernels, so the generic row does not claim a single processing state.

The proposal's ownership audit found no generic barley row or direct recipe demand across the bundled corpus. Broad `barley` and `orge` searches gain a clearly named general-grain choice; existing qualified searches remain available.

Ledger sources and decisions are on the `ingredient-ref-barley` record. The proposal is [WP03 Section F generic barley grain identity review](../../proposals/wp03-section-f-generic-barley-grain-identity-review-20261013-r52.md).

No tests were run because this change only adds database JSON data. Section F remains open.
