# WP03 Section F Balboula / Belboula Picker Hold

Integrated 2026-10-13 under the still-open [Section F regional cereal checklist](../../../RecipeBook-global-ingredient-catalog-plan.txt#L2555).

## Decision

Keep generic `balboula` unallocated and preserve the existing R20 `belboula` alias on `ingredient-ref-barley-couscous`. Do not extend the alias to the differently spelled `balboula`, create a generic Balboula row, or add a new ledger candidate. Sources use the names for overlapping but non-identical products and preparations, including barley couscous, boiled barley semolina, cracked barley, and mixtures based on other cereals. No Québec-facing standalone display or bundled recipe demand was found. Add no form, measure, recipe link, conversion, yield, or substitution.

## Evidence and checks

- The primary 2014 [barley-semolina study](https://www.ijeijournal.com/papers/Vol.4-Iss.2/E04023144.pdf) distinguishes boiling-water-cooked and dried `Belboula` from steamed barley couscous. Its density, cooking-time, and particle-size results apply to its prepared experimental samples only.
- A WIPO/OMPIC [Moroccan gastronomy study](https://www.wipo.int/export/sites/www/ip-development/en/docs/Scoping_Study_en_Morocco.pdf) describes Belboula as barley gruel and cracked-barley preparations. Current seller pages from [Dar Sebti](https://darsebti.ma/fr/categories/semoules) list Balboula products with barley, corn, and a five-cereal mixture alongside barley couscous.
- DARI's [barley-couscous page](https://www.couscousdari.com/en/barley-couscous) calls its own product `Belboula`; that supports the existing product-specific alias, not a global crosswalk. A [French-language retailer](https://www.maboucheriesolidaire.com/epicerie-fine/244-balboula-orge-cooperative-500g.html) also describes Balboula d'orge as cracked barley semolina for soup or porridge. A Québec bread listing uses `orge finement concassée` only as a composite ingredient.
- The proposal audit counted 1,367 active references, 100 forms, 64 legacy candidates, 1,699 research-ledger records, 114 manifest-listed recipes, and 1,123 ingredient rows. `belboula` continues to return the barley-couscous reference; `balboula` has no exact owner, and the bundle has no related recipe demand.
- The checklist, roadmap, and progress log now record this hold. No catalog or ledger data changed.

The full source register, ownership and picker projection, corpus audit, and numeric/substitution limits are in the [R41 proposal](../../proposals/wp03-section-f-balboula-belboula-picker-boundary-hold-20261013-r41.md). No tests were run because this integration changes documentation only.
