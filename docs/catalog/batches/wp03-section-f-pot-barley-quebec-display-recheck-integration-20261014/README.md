# WP03 Section F R110: pot-barley Québec display recheck

## Disposition

Retained the existing provisional `pot barley / orge en pot` display, with `Scotch barley` as its English alias and no French alias. This is a documentation-only review: no reference, form, ledger, recipe, or runtime data changed. Final independent Québec bilingual approval remains open.

The sources do not provide a clean replacement. OQLF's `orge mondé` names hulled barley; TERMIUM groups pot, hulled, and Scotch barley under that term; and the federal English/French food specifications use inconsistent cross-language mappings. Current Canadian French product listings also conflict, including paired English/French Metro pages for the same UPC. Keep `orge mondé(e)` and `orge entière` off the pot-barley row, and do not add a constructed process phrase as an alias.

The current picker result for `orge en pot` remains the existing row, while `orge mondé` remains with hulled barley. The bundled 114 recipes / 1,123 ingredient rows have no pot-barley demand. No measure, density, conversion, yield, or substitution is supported.
