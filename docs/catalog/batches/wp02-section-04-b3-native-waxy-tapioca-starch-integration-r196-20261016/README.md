# WP02 Section 04 B3 R196: native waxy tapioca starch

## Decision

Added identity-only `native waxy tapioca starch / amidon de tapioca cireux natif` as `ingredient-ref-native-waxy-tapioca-starch` in `FLOUR_AND_STARCH`. The only alias is English `waxy cassava starch`, supported by primary research. The French display remains provisional: Québec references support its wording components, but no current Québec label attests the complete compound.

The current Canadian Allzone listing names waxy tapioca starch as a native sourcing option and reviews grade, producer, package, documentation, and orderability by quotation. SMS independently identifies native waxy tapioca starch made from selected waxy cassava varieties; research supports the material boundary. The Montréal Québec Food Directory listing is only evidence for the ingredient phrase `amidon de tapioca`, not a waxy product.

## Data boundaries

Kept the new identity separate from generic, modified, and resistant tapioca starch, edible cassava flour, pearls and granules, Brazilian polvilho, and waxy maize/rice starch. The generic tapioca row remains unchanged. No forms, measurements, density, mappings, conversions, yields, recipe links, or substitutions were added. The measurement state records no supported kitchen value. The 114-recipe/1,123-row bundle contains no matching demand.

## Evidence and validation

The ledger record contains four new source IDs and reuses four registered OQLF/Allzone sources at their original URLs. No source URL was added under a duplicate ID. Static package, schema, catalog freshness, source ownership, corpus, encoding, and whitespace checks passed. No software tests or emulator checks were run because this change only adds database JSON data.
