# WP04 Section P R463 — salmon-jerky hold

Recorded on 2026-10-17 after review of the [R463 proposal](../../proposals/wp04-section-p-next-seafood-review-r463-20261017.md).

## Decision

Keep `salmon jerky / jerky de saumon` unallocated in active references, forms, legacy mappings, and the research ledger. Québec and Canadian listings establish a marketed preparation, but an active salmon-only row would make the broad `jerky` query return only salmon while the existing beef-jerky candidate remains unresolved. R169 expressly excluded the preparation without deciding it; R463 resolves this bounded follow-up as a hold.

The recipe bundle has no matching demand. No catalog, ledger, generated file, recipe, or application data changed. This documentation-only decision needed no tests. Section P remains open.

## Evidence reviewed

- Aliments du Québec lists **Jerky de saumon** and a separate hot-smoked/dehydrated salmon-jerky product. Their ingredients, processing, and package sizes remain product-specific.
- La Boucanerie d’Henri names and describes its own hot-smoked Atlantic salmon jerky; its reported 50% weight loss and refrigerated storage apply to that product only.
- A British Columbia seller uses **Salmon Jerky**, while a Québec wholesale catalogue lists **Jerky Saumon Fumé**. Neither supports a universal process or storage state.
- OQLF's `charqui` entry concerns dried meat and does not supply a fish-specific French term. R22's beef-jerky candidate stays unresolved and unchanged.

All five product sources remain proposal-local because the disposition adds no ledger record. Section P remains open.
