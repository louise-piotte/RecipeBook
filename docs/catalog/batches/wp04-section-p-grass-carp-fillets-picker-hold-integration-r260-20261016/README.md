# WP04 Section P R260 — frozen grass-carp fillets picker hold

Integrated the [R260 proposal](../../proposals/wp04-section-p-next-gap-review-r260-20261016.md) as a documentation-only hold.

## Decision

Keep frozen grass-carp fillets (*Ctenopharyngodon idella*) outside active references, forms, legacy mappings, and the research ledger. PriceSmart Foods lists a Canadian frozen, sliced grass-carp fillet product; Québec government and OQLF sources identify the species as `carpe de roseau / grass carp`, but the reviewed Québec sources do not attest the combined French frozen-fillet product phrase. CFIA's Fish List identifies the same species as `Grass Carp` with no French name and separately lists `Amur Carp / Carpe Herbivore`.

Even with empty aliases, the proposed bilingual display would make broad `carp` and `carpe` picker searches return this one product row. Generic carp and common carp remain held for the same picker-boundary concern. The complete 114-recipe, 1,123-row bundle has no matching demand. Keep the candidate, aliases, forms, measurements, recipe links, conversions, yields, and substitutions inactive pending clearer picker behavior and Québec product-name evidence.
