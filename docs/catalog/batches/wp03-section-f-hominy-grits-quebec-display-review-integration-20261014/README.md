# WP03 Section F R111: hominy-grits Québec display review

## Disposition

Retained `hominy grits / gruau de maïs` as the current bilingual display, but kept the French wording provisional. Statistics Canada's human-food code directly maps the pair, while OQLF and current Québec culinary products also use `gruau de maïs` for generic corn grits. No reviewed source provides a clearer hominy-specific Québec food name.

Keep the existing identity alias-free and distinct from ordinary corn grits, cornmeal, whole-kernel hominy, polenta, and prepared porridge. Add no aliases, forms, measures, conversions, yields, recipe links, or substitutions. No catalog or ledger data changed; independent Québec food-name review remains open.

## Evidence and review

- [Statistics Canada MDFoodCode](https://www.statcan.gc.ca/en/statistical-programs/document/3503_DLI_D12_T22_V1_B.pdf) gives `Hominy grits / Gruau de maïs` as a direct human-food classification pair.
- [OQLF's gruau de maïs entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/2088614/gruau-de-mais) is scoped to brewing and includes generic corn-grits terms.
- Current Québec-facing wording on [Bob's Red Mill Canada](https://www.bobsredmill.ca/produit/cereales-chaudes-de-gruau-de-mais-cremeux) and [La Moisson](https://lamoisson.com/products/gruau-de-mais-blanc-cremeux-creamy-white-corn-grits) uses `gruau de maïs` for ordinary white-corn grits.
- Full source limits, product boundaries, picker projection, and corpus scan are in the [R111 proposal](../../proposals/wp03-section-f-hominy-grits-quebec-display-review-r111-20261014.md).
