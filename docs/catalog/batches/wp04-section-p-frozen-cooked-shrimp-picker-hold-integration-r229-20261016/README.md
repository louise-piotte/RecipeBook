# WP04 Section P R229 — frozen cooked shrimp picker hold

Integrated the [R229 seafood review](../../proposals/wp04-section-p-next-seafood-gap-review-r229-20261016.md).

## Decision

Keep generic `frozen cooked shrimp / crevette cuite surgelée` unallocated. Current Costco and Mayrand
listings establish this frozen, cooked product group, but the phrase-first picker would make a
frozen-only row the sole result for `cooked shrimp / crevettes cuites`. Metro currently uses those
shorter names for another prepared-seafood listing without disclosing frozen state. Do not add an
active reference, alias, form, legacy identity, ledger candidate, measure, recipe link, conversion,
yield, or substitution.

The bundled corpus contains no shrimp demand. Reopen when state-aware search can preserve the frozen
qualifier or a reviewed cooked-shrimp parent/state model can present both products without disrupting
the canned-cocktail boundary.
