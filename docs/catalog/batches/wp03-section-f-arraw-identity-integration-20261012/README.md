# WP03 Section F: arraw identity integration

Integrated `ingredient-ref-arraw` as `arraw (millet granules) / granulés de mil (arraw)` in `GRAIN_AND_CEREAL`, with English alias `millet arraw` and French aliases `arraw de mil` and `arraw mil`.

The identity is specific to millet-derived arraw. Maize arraw, millet flour/soungouf, thiéré, thiakry, Sankhal, and prepared dishes remain separate. The ledger preserves four source-specific recipe amounts (200 g, 1 kg, 250 g for six people, and 300 g for four servings) without deriving serving conversions or a default measure. The reported millet-flour alternative in one porridge is recorded without a replacement ratio or active substitution rule. No forms, density, mappings, conversions, yields, recipe links, or runtime substitution rules were added. The bundled recipe corpus has no matching demand.

The source register, ownership/picker review, and exact observation limits are in [the proposal](../../proposals/wp03-section-f-arraw-millet-granules-identity-review-20261012.md).

Static package/catalog/ledger/ownership/corpus/encoding/whitespace checks were run after integration. No app tests or emulator checks were run because this change only adds database JSON data. Section F remains open.
