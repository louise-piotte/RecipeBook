# WP03 Section K pe-tsai / Napa cabbage alias-boundary hold (2026-10-15)

## Decision

Keep pe-tsai / pé-tsaï and its spelling variants outside active references and aliases. Canadian
taxonomic and terminology records link pe-tsai to the pekinensis group and to nappa terminology,
but OQLF and horticultural sources preserve multiple Chinese-cabbage market types, including
Napa/Won Bok and pe-tsai. Current Québec retail wording reviewed here identifies Napa/nappa
specifically; it does not establish that every pe-tsai listing refers to the Napa market type.

Do not create a second row without a market-level identity that can coexist with the existing Napa
cabbage reference. Adding pe-tsai spellings to Napa would make the shared `tsai` query return Napa
and Tatsoi. Keep the umbrella `Chinese cabbage / chou chinois` wording unassigned. No catalog or
ledger change, recipe link, form, measure, density, mapping, conversion, yield, or substitution was
made. The bundled corpus has no matching cabbage demand; Section K remains open.

See the [R122 pe-tsai / Napa boundary review](../../proposals/wp03-section-k-pe-tsai-napa-alias-boundary-review-r122-20261015.md).

This is a documentation-only hold. No app, Gradle, instrumentation, emulator, or deployment tests
were run; the updated `AGENTS.md` rule also exempts JSON-only database additions from testing.
