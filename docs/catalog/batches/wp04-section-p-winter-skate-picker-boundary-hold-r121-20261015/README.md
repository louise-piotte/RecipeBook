# WP04 Section P winter-skate picker-boundary hold (2026-10-15)

## Decision

Keep winter skate / `raie tachetée` (*Leucoraja ocellata*) outside active references and the shared
research ledger. CFIA supports the species-qualified Canadian name pair, but a lone row would make
broad `skate` and `raie` searches appear resolved even though CFIA applies those market names to
multiple taxa. Current Québec skate-wing listings do not identify a species. Do not use `big skate`
or `eyed skate` as aliases: CFIA assigns `Big Skate` to a different species.

No reference, alias, ledger record, form, measure, recipe link, conversion, yield, or substitution
was added. The 114-recipe / 1,123-row bundled corpus has no matching skate demand. Revisit if the
picker can preserve shared-name scope or a current Québec product identifies *L. ocellata*.
Section P remains open.

See the [R121 winter-skate review](../../proposals/wp04-section-p-winter-skate-picker-boundary-hold-r121-20261015.md).

This is a documentation-only hold. No app, Gradle, instrumentation, emulator, or deployment tests
were run; the updated `AGENTS.md` rule also exempts JSON-only data additions from testing.
