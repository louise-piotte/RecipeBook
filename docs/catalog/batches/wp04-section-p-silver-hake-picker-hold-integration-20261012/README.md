# WP04 Section P — silver hake picker hold

Keep silver hake (*Merluccius bilinearis*) outside the active ingredient catalog and evidence
ledger for now. OQLF and DFO support the species-specific name pair `silver hake / merlu argenté`,
but the CFIA Fish List also assigns `Silver Hake` to *M. hubbsi* and uses `Merlu Argenté` for that
species under `Atlantic Whiting`. A phrase-first picker that returns only the proposed row would
hide the market-name overlap instead of presenting the ambiguous species choice.

Do not create an active reference, candidate record, aliases, forms, measures, recipe links,
conversions, yields, or substitutions. Do not add broad `hake`, `whiting`, or `merlu` aliases to a
future candidate. The full recipe bundle has no matching ingredient demand;
mixed-species CNF portions and biological fish sizes do not establish a *M. bilinearis* kitchen
measure. Revisit allocation if picker behavior can expose the collision or exact species-qualified
product evidence changes the boundary.

This completes only the silver-hake name and picker-boundary review. The wider Section P seafood
review remains open. See the [full proposal and source register](../../proposals/wp04-section-p-next-seafood-batch-review-20261012-root.md).

Documentation-only hold. No database JSON changed, so no app tests or emulator checks were run.
