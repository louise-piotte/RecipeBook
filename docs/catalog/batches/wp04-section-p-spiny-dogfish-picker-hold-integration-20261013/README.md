# Spiny dogfish picker-boundary hold

Kept Atlantic spiny dogfish, *Squalus acanthias*, outside the active picker and research ledger. CFIA assigns `Spiny Dogfish` to both *S. acanthias* and the distinct Pacific species *S. suckleyi*. Adding a qualified Atlantic row would make broad English `spiny dogfish` / `dogfish` and French `aiguillat` searches return that one candidate. OQLF supports `aiguillat commun` for *S. acanthias*, but the current search cannot preserve the species choice for those broader terms.

No catalog or ledger data changed. The proposal records the ownership audit, query projection, recipe-demand scan, and source limits: [WP04 Section P spiny dogfish species and picker-boundary review](../../proposals/wp04-section-p-spiny-dogfish-species-picker-boundary-review-20261013-round48.md).

This documentation-only hold needed no tests. Section P remains open.
