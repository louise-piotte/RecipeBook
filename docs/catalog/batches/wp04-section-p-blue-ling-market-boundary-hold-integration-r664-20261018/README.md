# WP04 Section P R664 — blue ling market-name boundary hold

## Decision

Hold *Molva dypterygia* outside active references, forms, legacy identities, and the research ledger. OQLF and DFO’s Québec Region pair `blue ling / lingue bleue` with this species, and a current Alberta supplier lists the fish with that bilingual name. The term evidence also documents the ambiguity: TERMIUM lists the exact pair for *M. macrophthalma* as well, and describes `ling / lingue` as names used across multiple taxa. [OQLF](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/1199109/lingue-bleue), [TERMIUM Plus](https://www.btb.termiumplus.gc.ca/tpv2alpha/alpha-fra.html?i=&index=frb&lang=fra&srchtxt=LINGUE+BLEUE), [DFO Québec Region report](https://publications.gc.ca/collections/collection_2014/mpo-dfo/Fs97-13-1254.pdf), [Salties product listing](https://www.salties.ca/products/fresh-blue-ling-filets-skin-off)

CFIA’s Fish List overview describes the common names it accepts for Canadian fish labelling and pairs those names with scientific names. Its current results include `Ling / lingue` for *Molva molva* and `Ling` for *Lota lota*; the review found no candidate-specific CFIA row for *M. dypterygia*. This is no confirmation located, not a finding that OQLF’s Québec name is inadmissible. [CFIA Fish List overview](https://inspection.canada.ca/en/food-labels/labelling/industry/fish/list), [CFIA results](https://active.inspection.gc.ca/scripts/fssa/fispoi/fplist/fpresults.asp)

## Picker and recipe boundary

Static projection through the current phrase-first picker shows that adding only the primary names would make `blue ling` and `lingue bleue` each return the candidate alone. It would also make the broader `ling` query replace its four current substring results with one species, and make `lingue` return only this candidate. TERMIUM’s multi-species records make those singleton results unsafe. No supplier-only alternate such as `Deepwater ling`, `Purple ling`, or `Black ling` is used to bypass the collision.

The manifest-listed recipe bundle has no matching demand: all 114 recipe files and 1,123 ingredient rows were scanned. No active data, aliases, recipe links, measures, conversions, yields, or substitutions were added. The hold does not claim a lack of food use, Canadian listings, or a Québec term.

## Validation

The proposal’s ownership audit, current picker projection, and recipe scan were rechecked against the active package. OQLF and Salties product pages have no ledger owners; the DFO report URL is already used for a different taxon/locator, and CFIA’s overview/results are shared sources. No source ID or ledger entry was allocated.

No software tests, build, emulator run, or deployment were needed because this is a documentation-only hold. See the [R664 evidence review](../../proposals/wp04-section-p-next-regional-fish-gap-review-r664-20261018.md). Section P remains open.
