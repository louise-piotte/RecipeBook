# WP02 Section E named pectin grade-class integration — 2026-10-12

## Catalog decision

- Added identity-only `yellow pectin / pectine jaune`, `Rapid Set pectin / Pectine Rapid Set`, and `Medium Rapid Set pectin / Pectine Medium Rapid Set` under `BAKING_MIXIN_AND_PANTRY`. The names follow the manufacturers’ published grade labels; OQLF supports the base French term `pectine` but does not standardize these specialized grade names.
- Independent Québec French review of the specialized grade displays remains open; the current French labels are source-based manufacturer terminology, not an OQLF ruling.
- These rows represent named grade classes, not shared supplier formulations. They have no aliases, density, unit mappings, forms, doses, conversions, yields, or substitutions.
- Kept X58 and 325NH95 supplier-qualified and separate. Louis François and Sosa use similar product names while documenting different compositions and operating conditions; neither brand’s exact product is a cross-supplier alias. Also held extra-slow-set pectin, Sosa’s exact low-sugar/acid-free/Fruit NH products, and branded Pomona/Ball products.
- Kept unqualified “low-sugar pectin” unresolved. The term does not identify one universal pectin type, calcium strategy, or commercial formulation.
- The full bundled recipe scan found no pectin mentions, product names, or ingredient rows. No recipe links changed.
