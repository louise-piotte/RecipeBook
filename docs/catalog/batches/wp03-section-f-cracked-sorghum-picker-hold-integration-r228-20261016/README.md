# WP03 Section F R228 — cracked sorghum picker hold

Integrated the [R228 review proposal](../../proposals/wp03-section-f-next-grain-gap-review-r228-20261016.md).

## Decision

Keep `cracked sorghum / sorgho concassé` unallocated. Current Canadian and Québec product labels use
the phrase as an ingredient in grain blends, but do not say whether it describes broken whole kernels,
a coarse grits product, or another milled grade. FAO's processing description confirms that sorghum
grains can be processed into coarse grits or flour, but it does not define the product in those blend
labels. Assigning the phrase to whole grain sorghum, sorghum grits, or sorghum semolina would claim a
relationship the sources do not establish.

Do not add an active reference, alias, form, ledger candidate, measurement, recipe link, conversion,
yield, or substitution. The recipe corpus has no matching demand. Reopen if a standalone Canadian or
Québec human-food product or authoritative specification establishes the product state and a
product-matched French name.
