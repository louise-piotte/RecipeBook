# WP04 Section P European sprat picker-boundary hold

## Decision

Keep *Sprattus sprattus* outside active references, forms, and the research ledger. CFIA assigns
the short English/French name `Sprat / Sprat` to *S. antipodum* and *Sprattus* spp. as well as
using French `Sprat` for *S. sprattus*. A new `sprat / sprat` row would make the shared picker word
look unique. OQLF supports `sprat` as the Québec French term, but that language evidence does not
resolve the collision.

Metro's Québec listing is a 160 g smoked, oil-marinated sprat product with no binomial; its mass is
SKU-specific and does not identify *S. sprattus*. Codex's salted-*S. sprattus* standard describes a
different product state. The bundle has no matching recipe demand. No forms, measures, recipe links,
yields, conversions, or substitutions were added.
