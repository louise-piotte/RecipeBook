# WP02 B2/B3 whole navy bean flour identity integration

## Decision

Added `ingredient-ref-navy-bean-flour` as `whole navy bean flour / farine de haricots Navy entiers` in `FLOUR_AND_STARCH`. The French display is provisional: Avena identifies the English product, while the French wording combines a whole-bean term with the product's `whole` qualifier. Both alias arrays remain empty.

The entry stays distinct from whole navy beans, generic white-bean flour, black bean flour, whole pinto bean flour, and Avena's separately named precooked whole navy bean flour. It has no forms, measurements, density, unit mappings, conversions, package yields, recipe links, or active substitutions. The recipe corpus contains no navy-flour demand; recipe `007#4` remains the canned whole-pinto-bean line with liquid.

## Ledger evidence

Six sources are attached to the identity record: Avena's product-family listing; OQLF's whole-bean term; Agriculture and Agri-Food Canada's crop classification; Metro Québec's whole-bean listing; Pulse Canada's flour-processing overview; and Avena's application article.

The application article compares whole and precooked whole navy-bean flour in one muffin egg-replacement exercise but gives no reusable replacement quantity or complete application method. This remains a `blocked_pending_evidence` ledger finding. No egg-substitution rule is active.
