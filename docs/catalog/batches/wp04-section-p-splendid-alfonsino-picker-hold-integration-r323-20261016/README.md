# WP04 Section P R323 — splendid alfonsino picker hold

Reviewed and integrated on 2026-10-16. Root verified Fisheries and Oceans Canada's Québec-region species-code list, the Québec Terra Nostra seafood listing, current Canadian retailer listings, and the historical DFO-hosted processing study.

Keep splendid alfonsino (*Beryx splendens*) outside active references and the research ledger for now. DFO distinguishes it as `slender alfonsino / alfonsin long` and lists *B. decadactylus* separately as `red bream / béryx commun`. Terra Nostra, a Québec supplier, lists both species under the consumer-facing name `Alfonsino`. Assigning that bare label to a single active species row would hide the known ambiguity; do not merge the species or attach `alfonsino`, `imperador`, `red bream`, or `kinmedai` as aliases to a future *B. splendens* row from this review.
