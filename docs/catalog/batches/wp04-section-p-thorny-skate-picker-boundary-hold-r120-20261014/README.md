# WP04 Section P thorny-skate picker-boundary hold

## Decision

Keep thorny skate / raie épineuse (*Amblyraja radiata*) outside active references and the research
ledger. CFIA uses the generic `Skate / Raie` pair for this and multiple other taxa. A single
species-qualified row would make the broad `skate` and `raie` searches look resolved, even though
Québec retail pages list only the species-unspecified `aile de raie / skate wing` product. OQLF
supports `raie` for the Rajidae family context, not this species alone.

Mayrand’s approximate 500 g wing listing is a retailer-specific product amount, not species evidence
or a recipe measure. The bundle has no matching demand. Do not add a generic wing identity, species
row, form, measure, recipe link, yield, conversion, or substitution.

were run.
