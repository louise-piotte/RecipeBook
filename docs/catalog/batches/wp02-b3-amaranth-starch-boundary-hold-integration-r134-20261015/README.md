# WP02 Section 04 B3 R134 — amaranth starch boundary hold

## Decision

Held starch isolated from amaranth grain outside the active ingredient references and research ledger. Research establishes an isolated starch fraction, while the reviewed Canadian and Québec product listings name amaranth grain or flour. OQLF supports the component terms for amaranth and starch separately, but the review found no product-specific Québec French name for a standalone food starch.

No reference, alias, form, ledger candidate, measure, recipe link, conversion, yield, or substitution was added. The bundled corpus has no matching ingredient demand. This documentation-only hold leaves WP02 Section 04 B3 open.

No tests were needed because no database JSON changed. See the [proposal](../../proposals/wp02-b3-amaranth-starch-canadian-quebec-boundary-hold-r134-20261015.md) and [global catalog plan](../../../RecipeBook-global-ingredient-catalog-plan.txt).
