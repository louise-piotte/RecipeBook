# WP04 Section P Argentine red shrimp picker hold — 2026-10-13

Integrated the [round-68 Argentine red shrimp review](../../proposals/wp04-section-p-argentine-red-shrimp-identity-boundary-review-20261013-round68.md).

## Decision

Keep *Pleoticus muelleri* outside active references, forms, and the research ledger. Argentine
government nomenclature, the CFIA Fish List, a Canadian seafood supplier, and a current Québec
wholesaler support the species and Argentine shrimp market wording. The CFIA row uses only
`Shrimp / Crevette`; the qualified name is supported as market terminology, not as a CFIA-approved
common-name pair.

With the proposed display `Argentine red shrimp / crevette rouge d’Argentine`, the phrase-first
picker would return this one species for unqualified `red shrimp` and `crevette rouge`. Keep those
broad color queries from appearing species-resolved. The recipe package contains no shrimp,
prawn, or crevette demand. Product grades and package weights belong to individual retail listings;
they do not establish a reusable count conversion, measure, density, yield, or substitution.

No catalog or research-ledger data changed. Revisit if the picker preserves the full geographic
qualifier or can retain broader red-shrimp choices, and a recipe or library requirement establishes
need.
