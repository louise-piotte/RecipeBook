# WP04 Section P R132 — green sea-urchin picker hold

## Decision

Held the whole/live green sea urchin, *Strongylocentrotus droebachiensis*, outside the active picker and research ledger. OQLF supports Québec French `oursin vert`, CFIA assigns broad sea-urchin names to more than one species, and a current Montréal fishmonger listing identifies a whole/live Québec product. The current phrase-first picker would nevertheless return a single hypothetical green-urchin row for broad `sea urchin` and `oursin` queries. The bundled corpus has no matching recipe demand.

No active reference, legacy candidate, ledger record, alias, form, measure, density, unit mapping, recipe link, conversion, yield, or substitution was added. Preserve the separate unresolved extracted-gonad/uni candidate and all oyster decisions. This documentation-only hold leaves Section P open.

## Validation

The proposal's OQLF, CFIA, DFO, retailer, picker, ownership, and full recipe-corpus evidence was reviewed. No tests were run because no database JSON changed. No shared catalog or ledger data changed.
