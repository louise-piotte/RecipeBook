# WP02 Section A German wheat-flour types — Québec French display review — 2026-10-12

Reviewed the five existing French displays for German wheat-flour types 405, 550, 812, 1050, and 1600. This wording review changes no catalog, ledger, or recipe data.

## Decision

Retain the current country-qualified displays:

- farine de blé de type 405 (Allemagne)
- farine de blé de type 550 (Allemagne)
- farine de blé de type 812 (Allemagne)
- farine de blé de type 1050 (Allemagne)
- farine de blé de type 1600 (Allemagne)

These are clear descriptive constructions in Québec French. Farine de blé is established in Québec food terminology, and French-language food sources use the construction farine de blé de type 405. The parenthetical country qualifier makes the classification's scope explicit. It is a catalog disambiguator, not a claim that this is an OQLF-attested full-grade term.

Keep French aliases empty. Do not add bare type-number searches, German aliases to the French field, North American or French grade crosswalks, or measurement behavior. A French retailer's product-specific Type 405/T45 equivalence claim is not adopted.
