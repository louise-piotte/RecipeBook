# WP04 Section P Naruto Maki Boundary Hold

Integrated 2026-10-13 under the open [preserved-seafood checklist](../../../RecipeBook-global-ingredient-catalog-plan.txt#L4207) and [fish-powder, fish-balls, and surimi checklist](../../../RecipeBook-global-ingredient-catalog-plan.txt#L4237).

## Decision

Keep naruto maki outside active references and forms until a bundled recipe selects the product. Canadian and Québec-facing retail/manufacturer sources identify a distinct steamed fish-paste cake with a red swirl, but the recipe corpus has no demand. A hypothetical row would make broad `fish cake` and `maki` searches return this one product. Keep it separate from fish balls, raw surimi paste, other kamaboko, imitation crab, and species identities. Add no alias, form, measure, recipe link, conversion, yield, or substitution.

## Evidence and checks

- [Aliments Toyo's Québec listing](https://alimentstoyo.ca/products/jp-naruto-maki-150g) uses `JP Naruto maki`; it was sold out when checked. [Ocean Food Company](https://www.oceanfoodcompany.com/fresh-sea-market) identifies Naruto Maki as a steamed kamaboko product with a distinctive red swirl and describes its own fresh, ready-to-eat line. Those sources do not establish one universal storage state or formulation.
- OQLF's [surimi entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/1199047/surimi) defines surimi paste as an input used to make imitation seafood; it does not define naruto maki. Retail package weights were not treated as portions or conversions.
- The proposal audit counted 1,367 active references, 100 forms, 64 legacy candidates, 1,699 research-ledger records, 114 manifest-listed recipes, and 1,123 ingredient rows. No dedicated naruto-maki owner or matching recipe demand was found. Existing fish-ball and crab-flavoured pollock identities remain separate; no new searchable row was added.
- The checklist, roadmap, and progress log now record this hold. No catalog or ledger data changed.

The full source register, exact ownership, picker projection, and recipe-corpus audit are in the [round-38 proposal](../../proposals/wp04-section-p-naruto-maki-product-boundary-review-20261013-round38.md). No tests were run because this integration changes documentation only.
