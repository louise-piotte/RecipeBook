# WP03 Section F white canjica maize identity — 2026-10-13

Integrated the [round-67 canjica review](../../proposals/wp03-section-f-canjica-white-maize-identity-review-20261013-r67.md).

## Decision

Added identity-only `white canjica maize / maïs blanc pour canjica` in `GRAIN_AND_CEREAL`, with
English alias `canjica white`. MAPA defines canjica de milho as partially or fully degerminated
*Zea mays* grains or grain pieces and distinguishes a white class. Yoki's current manufacturer page
identifies a white product; Canadian retail wording supports `Canjica White`, and Québec retail
wording supports `maïs blanc pour canjica`.

The research ledger records the manufacturer's 50 g / ⅓ `xícara de chá` serving as a product-specific
portion observation. Its cup capacity and filling method are unstated, so the observation does not
create a reusable conversion or density. The reference has no forms, unit mappings, recipe links,
package yield, cooking yield, or substitutions. The bundled recipe corpus has no canjica demand.

Keep white dry canjica grain separate from corn kernels, hominy corn / `maïs lessivé`, hominy grits,
yellow crushed `canjiquinha`, and prepared canjica/mungunzá dessert.

## Checks

- Exact candidate ownership and recipe scans found no pre-existing row or bundled recipe demand.
- No app tests or emulator checks were run because the change only adds database JSON data.
