# WP03 Section F precooked durum-wheat boundary hold (R247)

The coordinator accepted the [R247 proposal](../../proposals/wp03-section-f-residual-grain-gap-review-r247-20261016.md) to keep the standalone precooked durum-wheat candidate unallocated.

ACEMA’s live Québec-facing page lists a Leader Price `Blé précuit` product with `Grains de blé dur précuit` as its ingredient, but does not establish whether the kernels remain whole or are cracked. Metro uses `BLÉ DUR PRÉCUIT (BOULGOUR)` in a separate mixed product, so that wording cannot safely be assigned to the existing bulgur reference. EBLY and INRAE support a distinct precooked whole-grain product process for EBLY, but do not prove that the Leader Price item follows it. OQLF names `blé dur` and notes its use for boulgour; it does not provide a picker-safe name for this processed product.

No active reference, form, legacy mapping, research-ledger candidate, measurement, recipe link, or substitution was added. The recipe corpus has no matching demand. Section F remains open pending product-specific evidence for kernel state and a Québec French name distinct from bulgur.

No software tests or emulator checks were run because this was a documentation-only hold; no database or application data changed.
