# WP03 R920 generic citrus-juice boundary hold

## Decision

Held a generic `citrus juice / jus d’agrumes` identity. Keep lemon, lime, grapefruit, and orange
juice species-specific. OQLF's general `jus de fruits / fruit juice` term does not establish a
citrus-only culinary identity. The CFIA standards define juices by named fruit and define a blend
as named fruit juices that each meet the applicable standard. The bundled corpus has no generic
citrus-juice line or named citrus-juice blend.

No reference, alias, form, measurement, recipe link, conversion, yield, or substitution was added or
changed. This is an evidence hold; it does not expand commercial-product coverage.

## Scope

Avoiding brand-name focus applies across ingredient types. Commercial brand, product-line,
flavour-family, SKU, and retailer-variant rosters remain out of scope because commercial-product
counts do not add ingredient diversity. The review selected a generic fruit-product boundary and
did not research commercial variants. Existing named-fruit juice rows and their evidence remain
intact.

## Validation

- Package counts remain 1,943 ingredient references, 204 forms, and 2,347 research-ledger records.
- The bundle remains 114 manifest-listed recipes and 1,123 ingredient rows; no row requests generic
  citrus juice or a generic citrus blend.
- The SARI residual import category was not used as culinary-identity evidence; its URL could not
  be opened through the research browser.
- No software tests, build, emulator, or deployment were run because this outcome changes only
  documentation and the ingredient database remains unchanged.
