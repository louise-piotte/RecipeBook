# R459 — Breaded shrimp identity integration

Added identity-only **breaded shrimp / crevettes panées** as a species-neutral `PROTEIN` reference. It represents the general bread-crumb-coated preparation and stays separate from breaded butterfly shrimp, popcorn shrimp, coconut butterfly shrimp, shrimp tempura, and shrimp species. The bilingual canonical names are directly searchable, so no aliases were added.

The projected broad picker result sets gain one relevant option: `breaded` grows from 3 to 4, `shrimp` from 8 to 9, and `crevettes` from 12 to 13. Narrow butterfly, popcorn, coconut, and tempura queries retain their prior owners. No matching recipe line exists in the 114-recipe / 1,123-row bundle.

Supplier count grades, package weights, the panko product's raw state, and Health Canada's six medium fried shrimp / 66 g serving remain source-specific. No forms, reusable measures, density, mappings, conversions, package yields, recipe links, or substitutions were added. Measurement research found no reusable value; substitution research remains not yet researched.

Static package normalization, generated-index freshness, ledger-schema validation, source ownership, picker projection, full-corpus matching, UTF-8/no-BOM, and scoped whitespace checks passed. No app or Android tests were run for this database-JSON addition under `AGENTS.md`.
