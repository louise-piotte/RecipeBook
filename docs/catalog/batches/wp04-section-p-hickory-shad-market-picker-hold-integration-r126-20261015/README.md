# WP04 Section P — hickory shad market and picker hold (R126)

Keep hickory shad, *Alosa mediocris*, outside active references and the research ledger until a
species-identified Canadian or Québec human-food listing or bundled recipe supports activation. DFO
Québec pairs `alose hickory / hickory shad` in a technical species-code list, but the bounded market
review found no current Canadian food product. U.S. fishery removals and a Canadian fishing-lure colour
do not establish a household ingredient market.

The hypothetical alias-free identity would make broad `shad` and `alose` searches return both
American shad and hickory shad. Keep FDA's short vernacular `Hick` out of aliases because it would join
an existing noisy chicken/chickpea substring search. Do not add `matowacca`, the scientific name,
other U.S. vernaculars, forms, measures, recipe links, conversions, yields, or substitutions.

This is a documentation-only hold; no catalog or ledger data changed. Ten source IDs remain local to
the proposal. At the end of the combined R126/R127 integration, the package has 1,476 references,
107 forms, 1,819 ledger records, 7,533 source entries, and 6,406 distinct source IDs; the bundle
remains 114 recipes / 1,123 ingredient rows. No tests were run for this documentation-only review.
