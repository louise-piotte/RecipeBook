# WP03 Section F sprouted rye berries naming hold (2026-10-12)

naming evidence. Second Spring and Everspring Farms support a real English-language product made from
whole rye kernels that are sprouted and dried. Current Québec evidence for `Seigle Germé` describes
fresh living germinations and does not establish the name of the dried product. `Grains de seigle
germés` remains a descriptive candidate translation, not an approved active display or alias.

Do not merge this candidate into unsprouted `rye berries / grains de seigle`, rye grain, cracked rye,
rye flakes, or malted rye. Keep the existing generic rye-grain USDA 169 g cup observation with its
source identity; it is not sprouted-rye evidence. Add no active reference, ledger record, alias, legacy
candidate, form, measure, mapping, recipe link, yield, conversion, or substitution. The full 114-file /
1,123-row corpus has no candidate or broad rye/seigle ingredient match.

Static ownership, source-prefix, package-yield, conversion, substitution, recipe-corpus, UTF-8/no-BOM,
mojibake, and whitespace checks passed. This was a documentation-only hold, so no app tests or emulator
