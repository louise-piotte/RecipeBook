# WP04 Section P snow crab / crabe des neiges picker hold

## Decision

Keep *Chionoecetes opilio* unallocated in the shared ingredient picker. OQLF and Québec fisheries sources establish `crabe des neiges / snow crab` as the Québec name for *C. opilio*. The CFIA Fish List, which supplies English and French common names acceptable for Canadian fish labels, also applies `Snow Crab` to three *Chionoecetes* taxa and `Crabe des neiges` to five. The shared picker cannot scope a name to Québec or show a taxonomic qualification, so one row could assign a Canadian-labeled product to the wrong species.

The 114-file / 1,123-row bundled recipe corpus has no snow-crab or *Chionoecetes opilio* demand. Recipe `019#8` asks for `jumbo lump crab meat` linked to the existing crab-meat identity and form; it does not request snow crab. Québec product sources describe whole live/fresh/frozen crab, sections, picked meat, mixed meat, and canned formats. Their commercial sizes and nutrition basis do not establish kitchen measures, density, edible yield, or a transferable conversion.

Reconsider if locale-scoped naming becomes available, a product-specific Québec source consistently identifies the taxon, or a recipe requests an identifiable snow-crab product. Keep this species review separate from the existing generic-crab hold.

## Data disposition

No active reference, legacy candidate, ledger record, alias, form, measure, density, mapping, conversion, yield, recipe link, or substitution was added. No app or emulator tests were run because this is a documentation-only hold with no database JSON changes.

See [the detailed snow-crab identity review](../../proposals/wp04-section-p-snow-crab-identity-boundary-review-20261012.md) for exact owners, picker projections, the recipe scan, source limits, and the source register.

Section P remains open.
