# WP02 Section 04 B3 — resistant tapioca starch integration (R126)

Added identity-only `resistant tapioca starch / amidon résistant de tapioca` as a separate
`FLOUR_AND_STARCH` reference. The English alias is `modified resistant tapioca starch`; the French
alias is `amidon de tapioca résistant modifié`. Both are resistance-qualified product-label phrases.
The broader `modified tapioca starch / amidon de tapioca modifié` row remains separate.

The Canadian and Québec finished-food labels support the identity and these narrow aliases. CFIA's
common-name pattern helps distinguish ordinary and modified starch naming but does not define RS4;
Health Canada's reviewed fibre list has no tapioca RS4 entry and explicitly is not exclusive. The
review does not infer regulatory approval from that list. Industrial product claims and study amounts
remain product- or formula-specific.

No forms, density, unit mappings, measurements, conversions, yields, recipe links, or active
substitutions were added. A scan of the 114 bundled recipes and 1,123 ingredient rows found no
resistant-tapioca demand. Eleven source IDs `WP02-B3-RESISTANT-TAPIOCA-STARCH-R126-20261015-S01`
through `S11` are recorded on the ingredient-reference ledger entry.

After the combined R126/R127 integration, static package validation, reference normalization,
generated-index freshness, picker projection, recipe-corpus scan, source-ID ownership, UTF-8/no-BOM,
local-link, and scoped whitespace checks passed. Final package totals are 1,476 references, 107 forms,
1,819 ledger records, 7,533 source entries, and 6,406 distinct source IDs. The bundle remains 114
