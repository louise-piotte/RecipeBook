# WP04 Section P R135 — Olympia oyster picker hold

## Decision

Keep *Ostrea lurida* outside active references and the research ledger until the picker can distinguish the taxon without making a broad common-name query appear uniquely resolved. Keep the generic fresh-oyster candidate, Pacific oyster, Eastern oyster, and dried oyster separate.

The CFIA Fish List assigns the exact searchable English label Olympia Oyster to both *O. conchaphila* and *O. lurida*, and places huître plate du Pacifique on the *O. conchaphila* row. OQLF pairs that French term with *O. lurida*. Adding a binomial to the display would not qualify the English search phrase in the current picker, so a broad Olympia Oyster query could misleadingly return one result. Seacore's Vaughan supplier listing identifies a Washington-origin *O. lurida* product, but that product-specific evidence does not resolve the general picker label collision. DFO's Pacific harvest prohibition concerns Canadian local harvest and does not establish absence of imported product sales.

No active reference, ledger record, form, reusable measure, recipe link, density, mapping, conversion, yield, or substitution was added. The supplier's size and case count remain listing-specific. The bundled corpus has no matching ingredient demand.

This was a documentation-only hold, so no tests were needed. See the [proposal](../../proposals/wp04-section-p-olympia-oyster-identity-review-r135-20261015.md) and [global catalog plan](../../../RecipeBook-global-ingredient-catalog-plan.txt).
