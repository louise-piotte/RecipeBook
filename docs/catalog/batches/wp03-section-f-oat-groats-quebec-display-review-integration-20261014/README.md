# WP03 Section F — Oat groats Québec-display review (R109)

Reviewed and integrated on 2026-10-14. Section F remains open.

## Decision

Retained the existing `oat groats / gruau d'avoine entier` display with empty alias lists. CFIA's
French oat survey uses the qualified phrase for whole groats and distinguishes steel-cut and rolled
oat products. OQLF defines bare `gruau` as a cooked oatmeal dish, so keep the whole-kernel qualifier.

The Québec Food Directory and Aliments du Québec use `amande(s) d'avoine complète(s)` for a La
Milanaise whole-groat product. A Québec retailer also uses `amande d'avoine complète` as a name for
steel-cut oats, and the manufacturer groups whole and cut oat terms on its product page. Do not add
the phrase as an exclusive alias for either row. Keep `avoine découpée` on the separate steel-cut-oats
reference and leave discouraged `avoine épointée` out.

The bundle has no groat demand across 114 recipes / 1,123 ingredient rows. No reference, form, alias,
ledger, measure, mapping, recipe link, conversion, yield, or substitution changed. This
documentation-only display review required no tests.
