# R618 — snakehead / Channa market-name boundary hold

Recorded a bounded hold for unqualified snakehead / Channa market wording under the open Section P fish checklist. No active reference, alias, form, legacy mapping, research-ledger candidate, or recipe link was added.

CFIA lists English `Snakehead` for multiple *Channa* species and for *Parachanna obscura*. Its French name pairings vary: several *Channa* entries include `Channa`, while *Parachanna obscura* is paired with `Lotte`. Québec government material distinguishes *Channa argus* as `Poisson à tête de serpent du Nord / Snakehead` and says snakehead fish are sold in North American Asian-food markets. The T&T listing and separate Marché C&T flyer use English and French terms, but they do not identify a matched bilingual SKU or its species.

The catalog still returns no fish result for `snakehead`, `poisson Channa`, or `poisson à tête de serpent`. `Channa` continues to return the existing Desi-chickpea reference through its `channa dal` form term. The 114-file / 1,123-row recipe corpus has no matching demand. Revisit if a Québec or Canadian package identifies its species or if matched bilingual products support a visibly multi-species group with coextensive English and French scope.

No software tests were run. This update changes only the plan, roadmap, proposal, and integration documentation; there is no active database JSON change to test.
