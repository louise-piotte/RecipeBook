# WP03 Section U R324 — lemon balm identity

Reviewed and integrated on 2026-10-16 after checking Kew, the bilingual OMAFRA culinary-herb profiles, OQLF terminology records, a Québec edible-plant nursery, Health Canada, and a Québec food-grade supplier.

Added identity-only `lemon balm / mélisse officinale` for culinary *Melissa officinalis* in category `HERB`. The only explicit alias is French `mélisse`. The bilingual OMAFRA profiles and Québec sources support the species-bounded culinary identity; the GDT entry attributes `mélisse` to AFNOR and pairs it with `lemon balm` and *M. officinalis*.

Keep lemongrass (*Cymbopogon citratus*) and lemon verbena (*Lippia citriodora*) separate. Do not add bare `citronnelle` or compound `mélisse-citronnelle`: the Québec GDT entry assigns bare `citronnelle` to lemongrass, while OMAFRA uses the compound for lemon balm, and the picker matches a full word inside a longer term. The nursery describes edible leaves and flowers and culinary uses; the food-grade powder page is supplier-specific evidence only. Neither supports adding a powder form or measurements. No forms, measures, mappings, conversions, recipe links, yields, or substitutions were added.

The 114 manifest-listed recipes contain no matching phrase or binomial. Measurement and substitution research remain open, and the broader Section U herb checklist remains open. Static package, generated-index, ledger-schema/source-ownership, picker, corpus, encoding, link, and whitespace checks passed. No software tests, builds, emulator checks, or deployment were run because this only adds database JSON data under `AGENTS.md`.
