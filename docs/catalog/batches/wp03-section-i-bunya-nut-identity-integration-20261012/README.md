# WP03 Section I bunya nut identity integration

Added identity-only bunya nuts / noix de bunya for the edible seed/kernel of Araucaria bidwillii, with bunya nut as the sole English alias. The French display is provisional pending Québec terminology review. Kept the species separate from pine nuts and generic nuts; no form, recipe link, measurement, conversion, yield, or substitution was added.

The sources establish species identity, Indigenous food use, Australian product naming, and descriptive French wording, but do not establish a Québec French product name. The ledger records no supported measure or substitute. The recipe corpus has no bunya demand.

Static bundled-package validation and generated-catalog consistency checks passed. No app tests or emulator checks were run for this database-data-only addition.
