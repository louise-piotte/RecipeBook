# WP03 Section F puffed Khorasan wheat identity integration

Added identity-only `puffed Khorasan wheat / blé khorasan soufflé` as
`ingredient-ref-puffed-khorasan-wheat` in `GRAIN_AND_CEREAL`, with the manufacturer-attested English
alias `Khorasan wheat puffs`. Kept intact Khorasan wheat, flakes, flour, generic puffed wheat, and
puffed spelt distinct; Kamut terms remain excluded as trademarks. No forms, measures, density,
unit mappings, conversions, yields, recipe links, or active substitutions were added.

The package serving of 1 cup (16 g) remains specific to the reviewed Nature’s Path SKU and is not
active catalog data. A recipe blog's puffed-brown-rice suggestion remains a rejected
recipe-specific finding because it gives no replacement amount or tested equivalence. The
114-recipe / 1,123-row corpus has no matching demand.

Sources and the picker/corpus audit are recorded in [the review proposal](../../proposals/wp03-section-f-next-gap-review-20261012-round10.md), including [Nature’s Path](https://naturespath.com/en-ca/products/puffed-khorasan-cold-cereal-np-ca), [La Moisson](https://lamoisson.com/products/cereales-au-ble-khorasan-souffle), and [OQLF’s blé khorasan entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/26533000/ble-khorasan).

Static package, generated-index, ledger, ownership, corpus, encoding, and whitespace checks were
run. No app tests or emulator checks were run because this only adds database JSON data and its
generated search index.
