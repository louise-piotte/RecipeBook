# WP03 Section I R679 — Makhana French match term

Integrated 2026-10-18. Added `noix de renard` as a French `matchTermsFr` entry on `ingredient-form-makhana-roasted-popped`, the existing roasted-popped form under species-qualified *Euryale ferox*.

## Naming and scope

WK Kellogg Co Canada's French recipe pairs `noix de renard` with `Makhana`, supporting the term as observed Canadian French usage for search. It does not establish a preferred Québec display or botanical synonym. The displayed form remains `graines de makhana grillées et soufflées`; the parent aliases and the existing species boundary remain unchanged.

Metro's Mr Makhana listing uses `graine de lotus soufflé` for a branded product, which conflicts with the separate sacred-lotus identity. Lotus terms remain excluded from the Makhana reference and form. The European Commission's French designation continues to support the existing descriptive form label, without being treated as Québec terminology authority.
