# WP02 A7 R472 wheat-meal boundary hold

Reviewed 2026-10-17. Generic `wheat meal` and `wheatmeal` remain unresolved and outside the active catalog. Retain `ingredient-ref-wheat-meal` only as `whole wheat meal / farine de blé entier brute`, with its existing alternate `farine de blé complet brute`.

The Natural Food Certifiers directory currently pairs `Organic Soft Wheat Meal / Farine de blé mou biologique`, but provides no process, particle size, composition, package, or use. A separate Québec government record describes a soft-wheat white pastry flour with the bran removed; no source ties that SKU to the NFC listing. OQLF's `farine de blé mou` wording is a soft-wheat flour term. This does not establish a transferable meal identity or a product-matched Québec name that separates it from flour.

No reference, alias, ledger source or decision, form, measure, recipe link, conversion, yield, or substitution was added. The 114-recipe / 1,123-row bundle has no matching wheat-meal demand. This documentation-only hold needed no software tests.

Sources and limits are recorded in the [R472 proposal](../../proposals/wp02-section-a7-wheat-meal-boundary-review-r472-20261017.md), including links to the [NFC directory](https://nfccertification.com/find-certified-products/), [Québec pastry-flour record](https://www.repertoirealimentsquebecois.gouv.qc.ca/Produit/Index/8203704), and relevant OQLF entries. The A7 work package remains open; reopen the candidate when product-specific process and Québec French evidence resolves the milling boundary.
