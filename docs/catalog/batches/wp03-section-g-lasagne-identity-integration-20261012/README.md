# WP03 Section G lasagne pasta-shape identity integration

Added identity-only **lasagna sheets / lasagne** as `ingredient-ref-lasagne` in `GRAIN_AND_CEREAL`. The OQLF food-pasta entry defines the term as a broad, flat pasta shape and supplies the Québec French preferred form `lasagne`, plural `lasagnes`, and English `lasagna` / `lasagne`. Barilla Canada and Catelli Canada corroborate current Canadian sheet-product wording, including `feuilles de pâtes lasagne` and `feuilles de lasagne`.

Keep the pasta shape distinct from the assembled lasagna dish, generic pasta, other shapes, and composition classes such as gluten-free, whole-wheat, or egg pasta.
