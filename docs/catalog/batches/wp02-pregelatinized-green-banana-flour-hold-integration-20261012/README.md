## Evidence and boundary

The 2017 IFT ingredient report describes P500 as pregelatinized green-banana flour that thickens without heat, and IAG's patent defines pregelatinized green-banana flour as native flour treated to disrupt some or all of the starch granules. The patent names NuBana P500 in product examples. [IFT 2017 report](https://www.ift.org/~/media/food%20technology/pdf/2017/08/0817_feat6_ingredients.pdf) · [IAG patent WO2018049242A1](https://patents.google.com/patent/WO2018049242A1/en)

Health Canada's accepted-fibre list supports the base English and French wording `green banana flour / farine de bananes vertes` for flour derived from raw unripe banana pulp, but it does not validate a pregelatinized product label. OQLF's `amidon prégélatinisé` entry defines and translates a starch term; it does not establish a French name for the flour state. [Health Canada](https://www.canada.ca/en/health-canada/services/publications/food-nutrition/list-reviewed-accepted-dietary-fibres.html) · [OQLF, amidon prégélatinisé](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/8357585/amidon-pregelatinise)

Terova's current NuBana page presents RS65 and N100. It does not list P500, but that absence alone does not establish that P500 was discontinued. EAS 1106:2023 excludes `instant banana flour`, but the catalogue does not define that term as pregelatinized flour. Keep RS65 and N100 separate because the current product page describes their own distinct application profiles. [Terova NuBana](https://terova.com/nubana/) · [EAC Standards Catalogue 2025](https://www.eac.int/documents?controller=download&file=177480db-3520-4d76-b686-1a6e0438a997&name=EAC+STANDARDS+CATALOGUE+2025.pdf&task=download.file)
