# WP04 Section P R113: Atlantic razor-clam nomenclature follow-up

## Disposition

Kept Atlantic razor clam outside active ingredient references and the research ledger. Québec
evidence now supports the species-qualified French name `couteau droit` and clarifies the local
cross-reference between *Ensis directus* and *E. leei*. The name evidence improves the identity
description, but it does not remove the picker ambiguity: phrase search would make broad `couteau`,
`razor clam`, and `clam` searches return this species as the only result.

CFIA continues to assign overlapping common names across *Ensis* and *Siliqua* species, and the
generic `ingredient-ref-clam` candidate remains unresolved. The 114 bundled recipes and 1,123
ingredient rows contain no clam ingredient demand. No active reference, alias, form, ledger source,
recipe link, measure, conversion, yield, or substitution was added. The earlier R51 hold remains in
force.

## Evidence

- OQLF’s [couteau entry](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/1198882/couteau)
  maps the food mollusc name to *E. directus*, and documents Québec naming limits for `couteau de
  l’Atlantique` and `rasoir`.
- The 2024 [Québec environmental-assessment appendix](https://www.ree.environnement.gouv.qc.ca/dossiers/3211-02-322/3211-02-322-24.pdf)
  lists `Couteau droit / Ensis directus`; the regional [Mange ton Saint-Laurent page](https://mangetonsaintlaurent.com/especes/couteau-droit/)
  cross-references *Ensis directus (Ensis leei)*.
- [WoRMS](https://www.marinespecies.org/aphia.php?id=876640&p=taxdetails) accepts *Ensis leei* and
  lists *E. directus* sensu Abbott, 1954 as an unaccepted synonym. This taxonomic source does not
  override Canadian food-label names.
- The [CFIA Fish List](https://inspection.canada.ca/en/food-labels/labelling/industry/fish/list)
  continues to show broad Razor Clam and Couteau names across several taxa. A current merchant
  listing has no scientific name, so it does not establish a species-specific Québec product.
