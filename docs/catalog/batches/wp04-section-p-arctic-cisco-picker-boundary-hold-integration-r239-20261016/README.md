# WP04 Section P R239 Arctic cisco picker-boundary hold (2026-10-16)

## Decision

Keep Arctic cisco (*Coregonus autumnalis*) / `cisco arctique` outside active references, forms, legacy mappings, and the research ledger. The species-specific bilingual name pair is supported, but adding it would make broad `cisco` searches resolve to one species. CFIA assigns cisco names across multiple *Coregonus* taxa, and OQLF describes cisco/corégone as a broader group. Reviewed regional-use evidence is historical and does not establish current Canadian retail availability; the reviewed product listings are U.S. listings without a binomial or Québec French product label. The bundled recipe corpus has no matching demand.

Add no aliases, forms, measures, recipe links, conversions, yields, or substitutions. Reopen if picker behavior can preserve a generic cisco choice alongside species-specific entries, or if a recipe or Canadian product source resolves the intended species and product state.

The proposal's 114-recipe / 1,123-row audit found no matching recipe line. Its picker projection found that adding the proposed bilingual display alone would make `cisco` return only Arctic cisco; no alias or form was needed to create that collision. Species-specific product, household-measure, yield, conversion, and substitution evidence was not established.

This integration is documentation-only. No database JSON, recipes, or application code changed; no software tests or emulator checks were needed.
