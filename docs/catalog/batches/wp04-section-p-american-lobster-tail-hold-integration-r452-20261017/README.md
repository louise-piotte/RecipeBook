# WP04 Section P R452 — American-lobster tail hold

Recorded on 2026-10-17 after root review of the [R452 proposal](../../proposals/wp04-section-p-lobster-tail-product-boundary-review-r452-20261017.md).

## Decision

Keep the American-lobster tail cut unallocated. Current Canadian and Québec-facing listings establish a distinct product, but any useful qualified English row such as `American lobster tail` contains the bare query `lobster tail`. The current phrase-first picker would return that single American-lobster cut, while OQLF's GDT assigns English `lobster tail` to `queue de langouste` and explicitly warns against `queue de homard`. This is a material bilingual naming collision.

The 114-recipe / 1,123-row bundle has no candidate demand. Add no active reference, alias, form, ledger record, measure, conversion, recipe link, yield, or substitution. Revisit if the picker can distinguish the complete qualified product phrase from a contained generic query or a common-name model can safely represent both product boundaries.

## Evidence reviewed

- OQLF, [queue de langouste (GDT)](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/8363515/queue-de-langouste), explicitly maps English `lobster tail` to the langouste tail and says it is not `queue de homard`.
- Poissonnerie La Mer's current Montréal product page, [Canadian Lobster Tails](https://www.lamer.ca/en/products/queue-de-homard-canadien-congele), attests the Canadian frozen-tail product and its French product-image wording. It does not supply a species name.
- MAPAQ's [Les crustacés du Québec](https://cdn-contenu.quebec.ca/cdn-contenu/adm/min/agriculture-pecheries-alimentation/peche/FI_crustaces-quebec_MAPAQ.pdf) lists American-lobster tail presentations; its commercial size bands are not recipe measures or yields.
- Metro's indexed listing pairs `Queue de homard surgelée` with *Homarus americanus*, but direct retrieval returned 403 during review. The indexed data are treated only as product/name evidence.

No source changes the search-collision decision. Section P remains open.
