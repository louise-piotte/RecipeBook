# WP04 Section P alewife / gaspareau picker hold

Keep the alewife / gaspareau (*Alosa pseudoharengus*) identity outside the active catalog and evidence ledger. OQLF and CFIA support the species-level food name, but DFO's Maritimes fishery plan and TERMIUM also document `gaspereau` / `gaspareau` as a collective name for alewife and blueback herring in some contexts. The current picker would present the species-only result for the shared French query without showing that broader fishery scope.

This is a catalog-readiness hold, not a denial of food use or the Québec species name. Add no reference, alias, candidate record, recipe link, measure, form, or substitution. Keep the broader Section P regional-fish review open.

Documentation-only reconciliation; no tests or emulator checks were needed.
