# WP02 B2/B3 — acorn starch Québec naming hold

Acorn starch is a real extracted-starch product class and is materially distinct from whole-matrix
acorn flour or meal. The reviewed Korean-market manufacturer and food-processing literature support
that boundary, but they do not establish a human-food Québec French display for the standalone
product. OQLF’s general distinction between *amidon* and *fécule* does not settle this compound name.

Keep acorn starch outside the active reference catalog and shared evidence ledger until a
Québec-facing human-food label or authoritative Québec terminology decision supports the French
name. Do not create `ingredient-ref-acorn-starch` or a candidate ledger record, and do not add
aliases, forms, measures, recipe links, conversions, yields, or substitutions. The current recipe
bundle has no matching demand.

This completes only the bounded acorn-starch naming review; broader WP02 B2/B3 flour and starch
coverage remains open. See the [full proposal and source register](../../proposals/wp02-b2b3-next-flour-starch-batch-20261012.md).

Documentation-only hold. No database JSON changed, so no app tests or emulator checks were run.
