# WP02 A7 R111: barley malt flour Québec display review

## Disposition

Retained both supplier-attested French displays provisionally: `roasted barley malt flour / farine de malt d'orge, pâle et grillée` and `light caramelized barley malt flour / farine de malt d'orge légèrement caramélisée`. The evidence supports these exact named products but does not establish either as an OQLF-standardized or Québec-retail term. Independent Québec bilingual review remains open.

Keep the two references distinct from each other, ordinary malted barley flour, roasted barley flour, and generic malt flour. Preserve empty alias arrays and keep `non-diastatic` scoped to the CaraBelga 30 product specification. Do not infer a universal caramelized-versus-roasted process boundary or ingredient interchangeability. No catalog, ledger, recipe, or runtime data changed.
