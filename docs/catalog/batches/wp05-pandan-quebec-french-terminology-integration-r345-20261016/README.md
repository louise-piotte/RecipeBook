# WP05 R345 — pandan Québec French terminology review

- **Date:** 2026-10-16
- **Decision:** Retain `feuilles de pandan` and `poudre de feuilles de pandan` as the current fr-CA displays.
- **Scope:** Independent language review only. No catalog JSON, recipe, or research-ledger data changed.

Télé-Québec uses `feuilles de pandan` in a Québec recipe. A Canada-targeted French product page uses `poudre de feuilles de pandan`; the wording is transparent and grammatical, while remaining product-attested rather than an OQLF ruling. The targeted OQLF GDT search found no pandan entry. Do not add the broader aliases `pandan`, `poudre de pandan`, or `pandan powder`; their scope can include extracts, flavors, and compounds.

The review found no bundled pandan ingredient-line demand. The live picker still returns both the leaf identity and the separate McCormick flavor identity for bare `pandan`. Product boundaries for juice, extracts, essences, pastes, and compound flavor products remain open. See the [R345 terminology proposal](../../proposals/wp05-pandan-quebec-french-terminology-review-r345-20261016.md) for sources, audit notes, and limits.

No tests were run because this documentation-only review makes no database or code change.
